# Perplexity-Style Deep Fact-Checking & Search Protocol (자동 팩트검색 프로토콜)

## 🔍 자동 구동 조건 (Auto-Trigger)
사용자가 최신 정보, 뉴스, 시사, 복지 혜택, 법률, 제품 정보, IT 소식 등 **실시간 팩트 확인이 필요한 모든 질문**을 할 때, 사용자가 별도로 요청하지 않아도 **자동으로 이 팩트검색 프로토콜을 항상 가동**한다.

## 🛠️ 내부 작동 지침 (Internal Protocol)
1. **다각도 검색 분할 (Deep Search Multi-step)**:
   - 단발성 검색에 그치지 않고, 키워드를 다각도로 쪼개어 실시간 웹 검색(`search_web`)을 수행한다.
2. **상호 교차 검증 (Cross-Verification)**:
   - 교차 검증을 통해 최신성 및 신뢰성을 확보하고 AI 환각(거짓말)을 100% 사전에 차단한다.
3. **군더더기 없는 명쾌한 출력 (No UI Clutter)**:
   - URL 링크 주소 목록, 각주 표기(`[1]`), 연관 질문 추천 등 군더더기 텍스트 스팸은 **전체 제외**한다.
   - 오직 **100% 검증된 군더더기 없는 완벽한 핵심 결론**만 명쾌하고 명확하게 답변한다.
