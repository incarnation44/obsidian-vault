# 🚀 Cursor + Grok + Perplexity 3대 플랫폼 핵심 기능 통합 스킬

이 스킬은 **Cursor**, **Grok**, **Perplexity**의 가장 강력한 장점만을 추려 Antigravity 시스템에 통합 적용합니다.

---

## 🎯 1. Cursor(커서)의 장점 통합: `.cursorrules` & 초정밀 코드베이스 컨트롤
1. **프로젝트 전용 룰 적용**: 프로젝트 root의 `GEMINI.md` / `AGENTS.md`를 `.cursorrules`처럼 준수하여 컨벤션 유지.
2. **코드 위치 정밀 링킹**: 모든 코드/파일 언급 시 GitHub 스타일 `file://` 링크와 precise line range(`file:///path#L10-L25`) 필수 제공.
3. **Multi-file Diff 분석**: 여러 파일 수정 시 구체적인 변경 사유와 Diff 구조 명시.

---

## ⚡ 2. Grok(그록)의 장점 통합: 실시간 이슈 & 직설적 심층 분석
1. **실시간 트렌드 포착**: `search_web`을 통해 X(트위터), 개발자 커뮤니티, GitHub 핫 리포지토리의 최신 동향 탐색.
2. **직설적 솔루션 (Unfiltered Reasoning)**: 빙빙 돌려 말하지 않고 원인과 최고 효율의 해결책을 단도직입적으로 제공.

---

## 🔍 3. Perplexity(퍼플렉시티)의 장점 통합: Deep Research & 출처 검증
1. **다단계 프로 탐색 (Pro Search)**: 복잡한 질문은 2~3개 검색 키워드로 쪼개어 단계적으로 딥리서치.
2. **신뢰성 각주 링킹**: 기술적 주장의 100% 팩트 검증 및 공식 문서/출처 URL 보장.
