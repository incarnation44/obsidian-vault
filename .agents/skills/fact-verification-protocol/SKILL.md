# Fact Verification Protocol (초정밀 팩트 검증 스킬)

## 📌 실행 가이드라인

### 1. 외부 URL 및 동영상 링크 검증
1. URL을 전달받았을 때 이전 대화 주제나 임의의 상상으로 내용을 지레짐작하지 않는다.
2. `read_url_content`를 가동하여 해당 페이지의 `og:title`, `og:description`, `<title>`, schema.org JSON 메타데이터를 원문 100% 추출한다.
3. 메타데이터 파싱이 불충분하거나 비공개/동적 페이지일 경우, 성급히 답변하지 않고 사용자에게 직접 캡처 화면 또는 정확한 텍스트 단서를 확인하여 팩트 기반으로 답변한다.

### 2. 최신 정보 & 시세 교차 검증
1. 단일 출처의 검색 요약에 의존하지 않고 최소 2개 이상의 검색 쿼리로 교차 검증한다.
2. 공식 발표일, 정식 릴리즈 날짜, 스트리밍 플랫폼(넷플릭스, 디즈니+, Hulu 등)을 원문 출처 단위로 명시한다.
