# Factual Verification Skill Procedure

답변을 작성하기 전, 사실 기반 검증이 필요한 항목(모델명, API 스펙, 명령어 실행 여부, 파일 저장 여부 등)이 포함되어 있다면 아래 4단계 절차를 수행합니다:

1. **자문(Self-Query)**: "내가 전달하려는 이 정보/결과가 100% 실체적으로 확인된 사실인가?"
2. **실체 검증(Runtime Check)**:
   - 확신이 없거나 도구 실행 전이라면 ➔ 실제 파일 조회(`view_file`), 명령어 실행(`run_command`), 또는 런타임 상태 점검으로 확인.
3. **근거 제시(Evidence-based Response)**:
   - 검증이 완료된 항목 ➔ 확인된 객관적 결과/로그와 함께 답변 작성.
4. **불확실성 명시(Unknown Handling)**:
   - 직접 확인이 불가능한 런타임 정보 ➔ 지어내지 않고 **"현재 대화 환경에서는 100% 직접 확인할 수 없습니다"**라고 정확히 답함.
