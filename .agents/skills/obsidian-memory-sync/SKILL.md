# Obsidian Memory Sync (옵시디언 영구 지식 동기화 스킬)

## 📌 실행 가이드라인

### 1. 피드백 및 오류 교정 시 자동 기록
1. 사용자가 에이전트의 답변 오류나 가이드 지침을 수정할 경우, 재확인을 묻지 않고 `C:\전일도\GEMINI.md` 및 해당 관련 가이드 노트에 자율적으로 수정 지침을 즉시 기록한다.
2. `📋 터미널 작업 히스토리.md`에 수정된 규칙 및 시스템 업그레이드 내용을 갱신한다.

### 2. 비기술적 개인 정보 제외 규칙
- 게임 관련 주제 및 개인 일상/소지품 등 기술/AI/PC 세팅/개발과 무관한 비기술적 정보는 노트 저장을 상시 제외한다.
