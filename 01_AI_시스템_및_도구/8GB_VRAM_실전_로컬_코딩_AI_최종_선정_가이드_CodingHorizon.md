## 💡 핵심 요약 (Level 0)
1. **"실행된다(Runs)"와 "일할 수 있다(Works)"의 극명한 차이**: 8GB VRAM에서 가장 큰 모델을 억지로 우겨넣으면 첫 프롬프트는 넘어가도, 스택 트레이스·테스트 결과·참조 파일이 들어가며 KV 캐시가 팽창하는 순간 속도가 '굳은 시멘트'처럼 굳어버려 개발자의 코딩 리듬을 파괴한다.
2. **벤치마크 1위가 아닌 "낭비가 가장 적은 모델(Minimum Waste Model)"이 승자**: 메모리 낭비(거대 모델), 문맥 낭비(명목상 컨텍스트), 추론 낭비(사소한 수정에 긴 독백), 특화 낭비를 배제했을 때 8GB 일상 코딩 드라이버 1위는 **`Qwen 2.5 Coder 7B Instruct (4-bit)`**로 최종 결론났다.
3. **8GB 개발자를 위한 실전 4대 모델 워크벤치(Workbench) 체계 구축**: 모델 박물관(20개 수집)을 만들지 말고, 1) 상시 코딩(`Qwen 2.5 Coder 7B`), 2) 난치병 로직 버그(`DeepSeek R1 Distill 7B/8B`), 3) UI/스크린샷 디버깅(`Gemma 3 / Qwen Vision`), 4) 환경 점검용 베이스라인(`Llama 3.1 8B`)의 4대 툴 데스크를 구축하라.

## 📜 상세 분석 및 타임스탬프 근거 (Level 1 Claims)

### 1. 로컬 코딩 AI의 환상과 8GB의 잔혹한 현실 [00:00~03:02]
- **로컬 코딩의 매력**: 구독료 $0, API 요금 $0, Rate Limit 없음, 코드 외부 유출 완전 차단.
- **꿈이 깨지는 지점**: 
  - 벤치마크 점수나 큰 이름만 보고 14B~30B를 다운로드함.
  - 첫 인사는 빠르지만, 실제 코딩에 들어가 에러 로그, 2개 파일, 테스트 실패 내역이 들어가는 순간 컨텍스트와 KV 캐시가 급증함.
  - 결국 초당 2~3토큰으로 추락하며 "굳은 시멘트 속에서 생각하는 느낌(thinking through wet cement)"을 주며 개발 흐름이 완전히 끊김.
- **코딩의 리듬(Coding Rhythm)**:
  - `질문 ➔ 확인 ➔ 패치 ➔ 실행 ➔ 수정 ➔ 재질문` 순환이 쾌적하게 돌아야 함. 이 리듬을 깨는 모델은 벤치마크 점수가 아무리 높아도 결국 버려짐.
- **로컬 코딩의 4대 직무**:
  1. *코드 설명(Explanation)*: 가장 쉬움. 거의 모든 모델이 그럴듯하게 설명함.
  2. *패치 작성(Patch Writing)*: 약한 모델이 밑천을 드러내는 곳. 3줄 수정에 3개 파일을 갈아엎거나 스타일을 파괴함 (절제력 필요).
  3. *디버깅(Debugging)*: 스택 트레이스와 잘못된 가정을 연결하는 논리 추론 영역.
  4. *저장소 문맥 인식(Repo Awareness)*: 타입, 함수, 테스트, 설정 파일이 얽힌 복합 문맥 수용력.

### 3. 최종 우승 모델: Qwen 2.5 Coder 7B Instruct [10:50~14:10]
- **선정 이유**: 
  - 8GB VRAM 안에서 **"가장 낭비가 없는 모델(Minimum Waste Model)"**.
  - 7B 크기로 VRAM 여유를 충분히 남겨 에디터와 16K~32K 컨텍스트가 들어와도 **GPU 100% 상주 및 초고속 응답(30+ tok/s)**을 유지.
  - 요구한 3줄만 정확히 고치는 외과수술적 절제력(Surgical Edit)과 코드베이스 스타일 보존 능력 탁월.
  - Apache 2.0 라이선스 및 에디터 플러그인 생태계 성숙.

## 🛠️ AI(나) 및 3-PC 사용자 환경 적용점 (Level 2 System Actions)

### 1. 메인 데스크톱 (Ildo 본체: RX 6600 8GB + Ryzen 5600X + 32GB RAM) 2-Tier 전략
- **Tier 1 (일상 코딩 드라이버 — 90% 업무)**:
  - **`Qwen 2.5 Coder 7B Instruct (4-bit)`**
  - Ollama/llama.cpp 구동, 컨텍스트 16K 설정.
  - 지연 시간 없는 즉각적 코드 패치, 리팩토링, 자동완성.
- **Tier 2 (심층 추론 및 배치 작업 — 10% 난제)**:
  - **`DeepSeek R1 Distill Qwen 7B/8B`** 또는 야간 배치용 **`Qwen 3.8-27B IQ4_XS`**.
  - 원인을 알 수 없는 딥 버그, 알고리즘 최적화 시 호출.

### 2. 로컬 코딩 워크벤치 4대 툴킷 규격화
```
[1. 일상 코딩] : Qwen 2.5 Coder 7B (리듬 유지, 빠른 패치)
[2. 난치성 추론] : DeepSeek R1 Distill 7B/8B (Thinking 기반 버그 분쇄)
[3. 비주얼 디버깅] : Gemma 3 (UI 깨짐, 브라우저 캡처 분석)
[4. 시스템 점검] : Llama 3.1 8B (환경 에러 검증용 표준 잣대)
```

### 3. 서브 노트북 (Dell Latitude 7440: Intel Iris Xe 내장)
- 본 영상의 결론대로, 로컬 AI는 "하드웨어 벽을 무리하게 넘으려 할 때" 망가짐. 노트북에서는 헌법에 따라 로컬 구동 0을 유지하고 클라우드 Gemini 3.8 Flash 100% 집중이 가장 현명함.
