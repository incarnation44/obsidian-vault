## 💡 핵심 요약 (Level 0)
1. **8GB VRAM 로컬 코딩 모델 압도적 1위 — Qwen 3 Coder 30B A3B**: 20B~30B급 5종 모델 실전 프론트엔드/리팩토링 테스트 결과, Qwen 3 Coder 30B가 작업당 2~3분대의 가장 빠른 완결 속도, 정확한 툴 콜링, 유일한 4대 과제 무결점 통과를 기록하며 8GB 체급 최강자로 등극했다.
2. **하네스(Agent Harness) 무게가 모델보다 더 치명적**: 동일한 Qwen 3 Coder 30B 모델이라도 경량 에이전트인 **Aider에서는 3분 만에 끝난 작업이, 시스템 프롬프트가 거대한 Claude Code/Roo Code에서는 30분 이상 지연**되거나 툴 호출 실패를 겪으며 사실상 사용 불능 상태에 빠졌다.
3. **경쟁 모델별 치명적 약점 규명**: Nemotron 3 Nano는 빠른 속도 뒤에 과도한 내부 독백과 코드 삭제 환각이 있었고, GLM 4.7 Flash는 툴 포맷 불일치로 탈락했으며, 덴스 모델인 Devstral 2 24B는 벤치마크 점수 대비 CPU 오프로드 속도 저하와 CSS 파괴 현상을 보였다.

## 📜 상세 분석 및 타임스탬프 근거 (Level 1 Claims)

### 1. 8GB VRAM 코딩 모델 선별 기준 및 테스트 환경 [00:00~02:51]
- **선정 기준**:
  1. 프로젝트 단위 리팩토링 및 UI 수정을 자연어 프롬프트로 완결할 지능.
  2. 시스템 RAM 오프로드 환경에서도 최소 5~10 tok/s의 실용적 속도 유지.
  3. 프롬프트 후 5분을 기다려도 실패하지 않는 높은 도구 호출(Tool Calling) 성공률.
- **테스트 장비**: 미니 PC, **NVIDIA RTX 4060 8GB VRAM + 32GB RAM**.
- **로컬 서버 & 에이전트**: LM Studio + **Aider in VS Code** (프롬프트 팽창이 없고 가장 얇은 경량 에이전트).
- **테스트 후보 5종 (20B~30B 4-bit Quant)**:
  1. *Nemotron 3 Nano 30B*: 초고속 추론으로 유명하나 코드 품질 우려.
  2. *GLM 4.7 Flash*: 최신 출시 모델, 도구 호출 호환성 검증 대상.
  3. *OpenAI OSS 20B (GPT-OSS 20B)*: SWE-bench 고득점의 초소형 모델.
  4. *Qwen 3 Coder 30B A3B Instruct*: MoE 기반 코딩 특화 모델.
  5. *Devstral 2 Small 24B*: 유일한 Dense 모델 (벤치마크에서 Gemini 2.5 Pro 능가).

### 3. 하네스 무게의 역설과 실전 운용 수칙 [07:40~09:23]
- **하네스 무게의 역설 (Aider vs Claude Code)**:
  - 8GB 제한 환경에서는 에이전트 하네스가 주입하는 시스템 프롬프트 크기가 성패를 가름.
  - Aider에서는 **3분** 만에 끝난 3번 칸반 과제가, Claude Code에서는 거대한 프롬프트와 툴 스키마로 인해 **30분이 넘도록 끝나지 않고 툴 호출 에러**를 뿜어냄.
- **8GB 로컬 코딩 3대 수칙**:
  1. 한 번에 전체 앱을 짜달라고 요구하지 말고, **작고 외과수술적인 단위 과제(Small Tasks)로 쪼갤 것**.
  2. 문맥이 길어지면 토큰 속도가 급락하고 환각(코드 삭제)이 발생하므로 **대화 기록과 컨텍스트를 자주 초기화(Clear Context)할 것**.
  3. 가벼운 CLI 에이전트(Aider 등)를 사용할 것.

## 🛠️ AI(나) 및 사용자 3-PC 환경 적용점 (Level 2 System Actions)

1. **메인 데스크톱 (Ildo 본체: RX 6600 8GB + Ryzen 5600X + 32GB RAM)**:
   - 본 영상의 테스트 하드웨어(RTX 4060 8GB + 32GB RAM)와 본체 사양이 완벽히 일치함.
   - **본체 로컬 코딩 모델 결정**: 8GB VRAM 환경에서 로컬 코딩 작업을 수행할 때 다른 20B~30B 모델 대신 **`Qwen 3 Coder 30B A3B Instruct (4-bit)`를 1순위 모델로 확정**.
2. **에이전트 하네스 선정 가이드라인**:
   - 로컬 8GB 모델을 본체에서 구동할 경우, 무거운 에이전트 대신 **Aider 또는 시스템 프롬프트가 슬림한 경량 툴**로 연결해야 30분 타임아웃 늪을 피할 수 있음.
3. **서브 노트북 격리 헌법 유지**:
   - 8GB 전용 GPU에서도 30B MoE 구동 시 2~3분이 소요되므로, Iris Xe 내장 그래픽 노트북에서는 로컬 구동을 시도하지 않고 클라우드 Gemini 3.8 Flash를 전담 활용하는 방침을 재확인.
