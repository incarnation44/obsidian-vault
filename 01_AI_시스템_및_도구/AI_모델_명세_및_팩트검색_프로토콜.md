# 🤖 AI 모델 상세 명세 및 벤치마크

이 문서는 사용 중인 **로컬 AI 모델(Ollama 기반)과 클라우드 에이전트 모델(Gemini)**의 파라미터 크기, 양자화(Quantization), 문맥 길이(Context Length), 파일 용량, 벤치마크 측정 속도를 정밀하게 기록한 명세서입니다.

---

## 💻 1. 로컬 AI 모델 상세 명세 (Ollama 엔진)

### 🟢 1) Qwen 3.8 / Qwen 2.5 (7B~8B) — 초고속 코딩 & 한국어 모델
- **모델 ID**: `845dbda0ea48` (Qwen2.5:7b) / `Qwen3.8` (업그레이드 대응)
- **파일 용량**: **4.7 GB ~ 5.5 GB**
- **아키텍처**: `Qwen2` / `Qwen3`
- **파라미터 수**: **7.6B ~ 8B**
- **양자화 (Quantization)**: **`Q4_K_M`** (고품질 4비트 양자화)
- **최대 문맥 길이 (Context Length)**: **32,768 tokens (32K) ~ 131,072 tokens (128K)**
- **임베딩 차원 (Embedding Length)**: 3,584 / 4,096
- **측정 생성 속도 (AMD RX 6600 가속)**: **`44.72 tokens/sec`** *(응답 소요 시간: ~4초)*
- **주요 기능**: 코딩, 파이썬/웹 개발, 자율 에이전트 수행, 한국어 자연어 대화, 문서 요약, 도구(Tools) 호출
- **업그레이드 포인트 (Qwen 3.8)**:
  - **한국어 완성도 대폭 향상**: 어색한 표현 및 번역투 완전 제거
  - **자율 코딩 & 에러 디버깅 강화**: 다단계 파이썬/JS 개발 및 에러 해결 성능 증대
  - **심층 추론 연산 향상**: 복잡한 문제 분석 능력 강화

---

### 🔵 2) DeepSeek-R1 (8B) — 심층 논리 추론 (Reasoning) 모델
- **모델 ID**: `6995872bfe4c`
- **파일 용량**: **5.2 GB**
- **아키텍처**: `Qwen3 (DeepSeek-R1 Distill Qwen 8B)`
- **파라미터 수**: **8.2 Billion (8.2B)**
- **양자화 (Quantization)**: **`Q4_K_M`** (고품질 4비트 양자화)
- **최대 문맥 길이 (Context Length)**: **131,072 tokens (131K / 128K)**
- **임베딩 차원 (Embedding Length)**: 4,096
- **측정 생성 속도 (AMD RX 6600 가속)**: **`38.64 tokens/sec`**
- **주요 기능**: 심층 논리 추론 (`<think>` 태스크), 수학 증명, 복잡한 알고리즘 분석
- **기본 파라미터**: `temperature = 0.6`, `top_p = 0.95`

# 🔍 Perplexity 알짜배기 팩트검색 프로토콜

Antigravity AI 에이전트에 추가 비용(월 0원, 추가 토큰 지불 없음)으로 **퍼플렉시티(Perplexity)급 실시간 웹 다각도 교차 검증(Deep Fact-Check) 기능**을 자동으로 구동하도록 이식한 시스템 규칙 문서입니다.

---

## 1. ⚙️ 작동 방식 (Deep Fact-Check Algorithm)

별도의 외부 유료 API 결제나 툴 설정 없이, 질문을 받으면 에이전트 내부 알고리즘에서 자동으로 가동됩니다.

1. **키워드 자동 분해보정**: 질문을 3~4개의 세분화된 검색 키워드로 분할합니다.
2. **실시간 웹 교차 검증**: `search_web` 도구를 통해 다수의 최신 웹 사이트를 다각도로 탐색합니다.
3. **성급한 부인 금지 (Strict Non-Denial)**: 1차 검색 결과 상위에 정보가 뜨지 않는다고 해서 *"공식 발표가 없다", "잘못된 정보이다"*라고 함부로 판단 및 단정 짓는 행위를 금지합니다.
4. **사용자 단서 역추적 검증 (User Clue Backtracking)**: 사용자가 특정 날짜(예: 8월 31일), 특정 플랫폼(넷플릭스 등), 미디어를 언급한 경우 **유튜브 공식 트레일러, 글로벌 애니 뉴스, 릴리즈 일정**까지 2~3차 확충 검색하여 팩트를 역추적합니다.
5. **클린 답변 출력**: 지저분한 URL 링크 스팸이나 무의미한 사설 없이 핵심 팩트와 명쾌한 결론(표, 요약)만 제공합니다.

---

## 2. 💰 토큰 비용 (비용 0원)

- **추가 결제 및 API 비용 0원**: 사용자 로컬 환경 및 Antigravity 시스템 내부 룰로 처리되므로 유료 구독이나 추가 토큰 지불이 전혀 없습니다.

---

## 3. 🚀 분야별 활용 이점

### 📰 1) 일반 최신 정보 및 시사/복지/정책
- 최신 법률, 지자체 복지 정책, 금융/부동산 LTV·DSR 규제, IT 하드웨어 최신 소식 등 **실시간 팩트가 중요한 질문**에서 거짓말 없이 100% 신뢰할 수 있는 정보를 제공합니다.

### 💻 2) 코딩 & 개발 작업
- **최신 라이브러리/API 지원**: AI 학습 컷오프 이후 변경된 최신 프레임워크(React, Next.js, Python 최신 라이브러리 등)의 문법 및 API 변화를 즉시 반영합니다.
- **최신 버그 & GitHub Issues 검증**: 최신 이슈 및 패키지 간 충돌 원인을 교차 검증하여 안 되는 구식 코드로 삽질하는 시간을 완전 방지합니다.

---

## 🧪 4. 검증 완료 사례 (2026-08-04)

- **검색 테스트**: *"NVIDIA 최신 그래픽카드 신제품 소식이나 가격 정보 최신으로 알려줘"*
- **결과**:
  - CES에서 발표된 **RTX 50 시리즈(Blackwell)** 라인업(5090, 5080, 5070, 5060)의 공식 MSRP 데이터 검증 완료.
  - **GDDR7 메모리 수급난 및 TSMC 웨이퍼 단가 상승**으로 인한 2026년 실유통가 20~30% 프리미엄 인상 현황 교차 검증 성공.
