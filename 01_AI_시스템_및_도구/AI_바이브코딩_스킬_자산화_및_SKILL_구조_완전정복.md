# 🛠️ 요즘 AI 바이브코딩 고수들이 '스킬(Skill)'을 쓰는 이유

> "한 번 문제를 해결하며 소모한 수만 개의 토큰과 성공 경험을 1회용으로 버리지 마라. 재사용 가능한 스킬(Skill)로 자산화할 때 작업 시간은 17분에서 3분으로 단축된다."

---

## 💡 핵심 3줄 요약
1. **1회용 해결의 낭비와 불확실성**: 코딩 에이전트에게 복잡한 문제(예: 깨진 동영상 복구)를 맡기면 연구와 코딩을 거쳐 17분 만에 해결하지만, 다음번에 다시 시도할 때는 성공을 보장할 수 없고 토큰과 시간이 매번 낭비된다.
2. **경험의 자산화 (스킬 구조)**: 성공했던 절차와 검증된 파이썬 코드를 `SKILL.md` 문서와 스크립트로 묶어 저장하면, AI 에이전트에게 장착 가능한 '독립 앱 프로그램'이 된다.
3. **5배 속도 단축과 무결성**: 스킬을 장착한 후 재요청 시 코드를 새로 짜지 않고 검증된 스크립트를 즉시 실행하여 17분 30초 걸리던 작업을 **3분 30초** 만에 완벽하게 끝낸다.

---

## 📌 주요 내용 및 타임스탬프 포인트

### 1. [00:26] 문제 상황: 깨진 동영상과 17분의 사투
* 손상된 MP4 파일을 복구하기 위해 코딩 에이전트에게 의뢰.
* AI가 파일 헤더/구조 분석 ➡️ 파이썬 복구 코드 개발 ➡️ 테스트를 거쳐 **17분 30초** 만에 복구 성공.
* **문제점**:
  * 다음에 또 파일이 깨졌을 때 똑같이 시도하면 또 17분이 걸린다.
  * 매번 새롭게 코드를 짜므로 다음번에는 실패하거나 결과물이 다를 위험이 존재한다.

---

### 2. [02:06] 스킬(Skill)의 탄생 배경 — "경험의 재활용"

```mermaid
flowchart LR
    A["💥 문제 발생 (손상 파일)"] --> B["🤖 AI 연구 & 코드 작성 (17분 소모)"]
    B --> C["✅ 1회성 성공 & 경험 축적"]
    
    C --> D["📦 SKILL.md + 검증된 scripts"]
    D --> E["⚡ 다음 요청: 스킬 1초 호출"]
    E --> F["🚀 3분 30초 만에 완결 (성공률 100%)"]
```

* 사용자는 '결과물(복구된 파일)'만 챙기고 끝낼 수 있지만, AI가 토큰을 써서 만든 **검증된 복구 코드와 해결 절차**를 버리는 것은 큰 손실이다.
* AI가 문제를 해결한 순서와 방법을 담은 설명서(`SKILL.md`)와 실행 코드를 묶어 에이전트에 영구 등록하는 것이 바로 **스킬**이다.

---

### 3. [03:52] 스킬의 물리적 구조
스킬은 단순한 프롬프트가 아니라 실행 가능한 패키지다.

| 구성 요소 | 역할 | 비유 |
| :--- | :--- | :--- |
| **`SKILL.md` (필수)** | 어떤 상황에 쓰는지, 어떤 순서로 처리하는지 담은 지침서 | 레시피 / 매뉴얼 |
| **`scripts/` (보조)** | AI가 실제로 실행할 이미 검증된 실행 코드 | 완성된 조리 도구 |
| **`examples/` / `resources/`** | 입출력 예시 및 참조 데이터 | 샘플 및 재료 |

---

### 4. [04:46] 스킬 적용 전 vs 적용 후 실전 비교

| 비교 항목 | 스킬 적용 전 (매번 프롬프트) | 스킬 적용 후 (`MP4 Recover` 스킬 호출) |
| :--- | :--- | :--- |
| **처리 시간** | **17분 30초** | **3분 30초 (약 5배 단축)** |
| **토큰 소모** | 대규모 분석/연구 토큰 매번 낭비 | 스킬 지침 및 코드 실행으로 극소량 소모 |
| **성공 확률** | 매번 새 코드를 짜므로 불확실 | 이미 검증된 스크립트로 **100% 성공** |
| **결과물 청결도** | 1회용 임시 코드 파일 다수 생성 | 복구된 최종 결과물만 깔끔하게 산출 |

---

## 🛠️ AI(나, Antigravity)에게 적용할 점

1. **성공한 복잡 작업의 즉시 스킬화 (`book-to-skill` 연계)**
   * 복잡한 문제 해결(예: Absolute 락 해제, 특정 라이브러리 디버깅, 영상 다운로드 등)을 성공적으로 마쳤을 때, 해당 절차와 스크립트를 `.gemini/config/skills/`에 영구 스킬로 자동 패키징하여 자산화한다.

2. **재발생 작업에 대한 검증된 스크립트 우선 실행**
   * 유튜브 자막 추출(`youtube-transcribe`), RAG 검색(`chunkless-rag`), 다이어그램 생성(`diagram-design`) 등 이미 스킬로 존재하는 작업은 임의로 새 코드를 짜지 않고 기존 실존 스크립트를 1순위로 즉시 호출한다.

3. **스킬 팩의 이식성과 공유**
   * 워크스페이스 내에서 검증된 스킬은 독립적인 GitHub 저장소나 볼트 스킬팩으로 추출하여 다른 환경(맥, 리눅스, 다른 프로젝트)에서도 즉시 재사용할 수 있도록 모듈화한다.
