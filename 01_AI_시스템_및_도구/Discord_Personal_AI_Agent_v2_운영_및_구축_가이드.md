## 📌 1. 시스템 개요 및 v2 아키텍처

단순한 질문-답변 챗봇을 넘어, 사용자의 집 PC 하드웨어와 실시간 웹 데이터를 직접 연동하여 밖에서도 스마트폰 디스코드로 집 PC를 제어하고 전문적인 코딩 페어 프로그래밍을 지원하는 24시간 자율형 AI 에이전트입니다.

```text
                             Discord (스마트폰/외부)
                                       │
                                       ▼
                              [1. Intent Router]
                                       │
       ┌──────────────┬────────────────┼───────────────┬──────────────┐
       ▼              ▼                ▼               ▼              ▼
  [실시간 검색]     [날씨/시간]      [금융/증시]      [PC 하드웨어]    [파이썬/코딩]
  (Google News)   (wttr.in/달력)   (네이버금융)     (psutil 실시간)  (AST 자가검증)
       │              │                │               │              │
       └──────────────┴────────────────┼───────────────┴──────────────┘
                                       ▼
                         [2. Context Data Grounding]
                           (2026년 8월 실시간 시각 주입)
                                       │
                                       ▼
                        [3. Multi-Tier Model Router]
                     Gemini 3.6 Flash ➔ Gemini 3.5 Flash ➔ 로컬 Ollama
                                       │
                                       ▼
                              [4. Output Validator]
                          (파이썬 문법 검사 + 코드블록 보존)
                                       │
                                       ▼
                              Discord (검증된 응답)
```

## 🛠️ 2. 핵심 5대 도구 및 기능

### 1) 눈 (Eyes - 실시간 데이터 수집기)
* **실시간 국내 증시**: 네이버 금융 API 연동으로 코스피/코스닥 실시간 지수 및 변동률 수집 (숫자 날조 원천 차단)
* **PC 하드웨어 모니터링**: `psutil` 및 드라이브 용량 실시간 조회 (5600XT CPU 점유율, 32GB RAM 사용량, C/D/E 드라이브 잔여 공간)
* **실시간 웹/뉴스 검색**: 구글 뉴스 RSS 파싱으로 스팀 신작, 롤 LCK 경기 결과, 알리익스프레스 세일, 스포츠 소식 실시간 수집
* **실시간 날씨**: `wttr.in` 기반 서울 및 주요 도시 기온, 체감 온도, 습도, 3일간 주간 예보 제공

### 2) 손 (Hands - 로컬 PC 제어 및 실행기)
* **파이썬 패키지 자동 설치**: 디스코드에서 `pip install 패키지명` 입력 시 집 PC에서 `pip install` 백그라운드 자동 실행 후 결과 회신
* **파이썬 코드 즉석 샌드박스 실행**: 디스코드에서 `!run 코드` 입력 시 임시 파일 격리 생성 후 15초 타임아웃 샌드박스에서 실행
* **옵시디언 메모 자동 저장**: `!저장 본문` 또는 `옵시디언에 저장해줘` 입력 시 `C:\전일도` 볼트에 자동 마크다운 문서 생성
* **GitHub 원격 푸시**: `!push` 입력 시 옵시디언 변경사항을 GitHub 저장소에 안전하게 커밋 및 푸시

### 3) 뇌 & 무결점 안전망 (Brain & Multi-Model Failover)
* **1순위 엔진**: Google Gemini 3.6 Flash (초고속 지능형 한국어 대화)
* **2순위 엔진**: Gemini 3.5 Flash / Flash-latest (503/429 일시적 서버 트래픽 발생 시 0.5초 만에 자동 우회)
* **3순위 엔진**: 로컬 Ollama `qwen2.5:7b` (인터넷 장애나 외부 API 완전 차단 시 집 PC RX 6600 GPU 가속 로컬 모델로 100% 오프라인 작동)

### 4) 자가 검증기 (Validator)
* **파이썬 AST 문법 검사**: AI가 코드를 작성할 때 `ast.parse`로 문법 오류(`if name == "main":` 등)를 사전에 차단
* **마크다운 코드블록 2,000자 분할기**: 디스코드 글자 수 제한 초과 시 코드블록(` ``` `)이 깨지지 않도록 열림/닫힘 태그를 유지하며 분할 전송

## 🚀 3. 24시간 무소음 자동 실행 설정

집 PC가 켜지면 콘솔 창 없이 백그라운드에서 무소음으로 자동 상주하도록 Windows 시작프로그램 레지스트리에 등록되어 있습니다.

* **등록 레지스트리 키**: `HKCU:\Software\Microsoft\Windows\CurrentVersion\Run\DiscordAIBot`
* **실행 명령어**: `pythonw.exe C:\bots\discord_bot.py`
* **싱글톤 소켓 락 (Port 19876)**: 프로세스가 중복으로 켜져 디스코드에 메시지가 두 번씩 찍히는 버그를 원천 차단
