# Grok Bot 요금 (한국 원화) — 안티그래비티 메모 정정

- 원본 출처: https://youtu.be/QzOzVIMuFhk (코드팩토리), 공식 요금 https://x.ai/bot , https://docs.x.ai/grok-bot/faq , https://docs.x.ai/developers/pricing

- 내 보관소 등록일자: 2026-08-15

안티그래비티가 적어 둔 "그록 봇 = X Premium 월 1.1만 원"은 틀린 제품이다. 채팅용 Grok, API, 이 Grok Bot은 요금이 다르다.

## 1. 이 Grok Bot (파일 고치고 코딩하고 사진 올리고 링크 요약)

단독 요금제는 없다. 아래 구독 중 하나에 포함된다. 주간 사용량이 들어 있고, 넘치면 모델·토큰 종량제. 한도 캡은 아직 없다.

| 플랜 | 달러 | 원화 (월) |
|---|---:|---:|
| Cursor Teams Premium (팀, 제일 싼 정식 좌석) | $120 /인 | 약 17만 원 |
| Cursor Ultra (개인) | $200 | 약 28.3만 원 |
| SuperGrok Heavy | $300 | 약 42.5만 원 |

한 번짜리 체험(trial)은 있다. 지금 쓰는 화면이 그 체험일 수 있다.

헤비하게 굴리면: 위 구독이 바닥이고, 주간 허용량을 넘긴 만큼 API 단가로 더 붙는다. 주간 허용량 숫자는 공개되어 있지 않아서 "월 2~4만 원"이라고 단정할 수 없다.

## 2. Grok 4.6 API (Cursor/코딩 도구에 모델만 붙일 때)

공식 단가 (프롬프트 20만 토큰 미만):

| | 100만 토큰당 | 원화 |
|---|---:|---:|
| 입력 | $2.00 | 약 2,830원 |
| 캐시 입력 | $0.50 | 약 710원 |
| 출력 | $6.00 | 약 8,500원 |
| 이미지 1장 (imagine) | $0.02 | 약 28원 |

20만 토큰 넘는 긴 요청은 입력 $4 / 출력 $12 로 두 배.

이건 "그록 봇" 구독이 아니다. 모델만 빌려 쓰는 종량제다.

## 3. X / grok.com 챗봇

X Premium·Premium+ 또는 SuperGrok 쪽 대화창이다. PC 파일·옵시디언·폴더 정리를 하지 않는다. 그록 봇 요금과 섞지 말 것.

## 적용할 점

- 이 비서(Grok Bot)를 쓰려면 Cursor Ultra / Teams Premium / SuperGrok Heavy가 필요하다. X Premium 월 1만 원으로는 안 된다.
- 안티그래비티 프리뷰 0원과 직접 비교하면, 그록 봇은 구독이 훨씬 비싸다. 대신 화면을 안 막고 꺼놔도 돌아간다.
- 코드 대량 분석만 싸게 하려면 봇 구독이 아니라 Grok 4.6 API ($2/$6)를 안티그래비티·Cursor에 붙이는 편이 맞다.
