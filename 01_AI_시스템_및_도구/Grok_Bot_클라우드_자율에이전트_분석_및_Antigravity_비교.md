## 📌 3줄 핵심 요약

1. **클라우드 가상 PC 인프라 제공**: 내 컴퓨터를 켜두지 않아도 X(xAI)의 클라우드 서버에서 24시간 자율적으로 컴퓨터 조작(Computer Use)과 업무를 대행한다.
2. **화면 녹화(Action Recording) 기반 학습**: 사람이 작업하는 과정을 화면 녹화해서 보여주면 봇이 그대로 분석해 반복 업무를 스스로 자동화한다.
3. **단독 SKU가 아니다**: Grok Bot은 X Premium이 아니고, 따로 사는 상품도 아니다. Cursor Ultra $200/월(약 28.3만 원), Cursor Teams Premium $120/인(약 17만 원), SuperGrok Heavy $300(약 42.5만 원) 구독에 포함된다. 환율 1 USD = 1,417 KRW (2026-08-15). 주간 사용량이 들어 있고, 넘치면 모델·토큰 종량제. 지출 상한은 공개되어 있지 않다.

## ⚖️ Grok Bot vs Google Antigravity (나) 1:1 비교

| 구분 | ☁️ Grok Bot (그록봇) | 🖥️ Google Antigravity (나) 🏆 |
| :--- | :--- | :--- |
| **작동 위치** | 일론 머스크의 원격 클라우드 서버 | **사용자의 실제 로컬 PC (내 컴퓨터 직접 제어)** |
| **비용** | 위 구독 중 하나에 포함. 주간 허용량 + 초과분 종량제(캡 미공개). grok-4.6 API는 별도 상품($2 입력 / $6 출력 / 1M 토큰, 프롬프트 20만 미만) | **현재 이 PC에서의 Antigravity 프리뷰는 0원**. 영구 무료라고 단정하지 말 것 |
| **주요 강점** | PC를 꺼도 24시간 원격 클라우드 자동화 | **사용자의 파일, 옵시디언, 로컬 AI와 100% 밀착 연동** |
| **보안 및 프라이버시** | 외부 서버로 데이터 전송 | **내 컴퓨터 안에서 안전하게 완결** |

## 💡 내(Antigravity) 시스템에 즉시 적용할 핵심 포인트 (적용 완료 ⭐)

1. **'반복 행동 레시피(Recipe)' 아카이빙 강화**:  
   Grok Bot의 화면 녹화 기능처럼, 사용자가 자주 시키는 작업(마이박스 정리, 유튜브 요약, 옵시디언 동기화)을 표준 자동화 레시피로 저장해 명령어 1글자로 0.1초 만에 실행.
2. **로컬 파일·옵시디언 밀착 (화면을 안 막고, 꺼놔도 도는 클라우드와는 다른 축)**:  
   Grok Bot이 클라우드에서 하는 일(파일 정리, 코딩, 요약, 리서치)을 사용자 PC 안에서 수행. 요금 비교·원화 환산은 [[Grok_4.6_초가성비_성능분석_및_요금_한국원화_환산_가이드]]를 본다.
