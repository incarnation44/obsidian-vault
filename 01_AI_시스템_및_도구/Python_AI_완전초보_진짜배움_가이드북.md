## 🧭 [1단계. 인공지능은 기존 프로그램과 무엇이 다를까?]
* **계산기 vs 인공지능:**
  * 계산기(기존 코딩): 사람이 1,000줄의 if-else 규칙을 일일이 작성.
  * 인공지능: 컴퓨터에게 수만 장의 사진(데이터)을 보여주고 스스로 규칙과 패턴을 찾게 만듦.
* **튜링 테스트:** 컴퓨터와 대화했을 때 상대가 사람인지 기계인지 구별하지 못하면 지능이 있다고 인정.
* **약인공지능(Narrow AI):** 특정 분야(바둑, 번역, 얼굴 인식)만 잘하는 AI (현재의 모든 AI).
* **기호주의 vs 연결주의 & 모라벡의 역설 (🚨 시험 족보):**
  * 기호주의: 사람이 직접 규칙 코딩.
  * 연결주의: 뇌세포 신경망을 모방해 데이터로 학습.
  * 모라벡의 역설: 사람에게 쉬운 시각/보행은 AI에게 어렵고, 어려운 수학 계산은 쉬운 현상.

## 🧭 [2단계. 컴퓨터는 사진과 글자를 어떻게 이해할까? (파이썬과 NumPy)]
* **모든 것은 숫자다:** 고양이 사진도 가로세로 픽셀의 숫자 표(행렬)일 뿐임.
* **NumPy(넘파이)를 쓰는 이유:** 파이썬의 일반 `for` 루프보다 연속 메모리 기반 **벡터화 연산**이 수십 배 빠름.
* **요소별 곱(`*`) vs 행렬 곱(`@`, `np.dot`):**
  * `A * B`: 같은 자리의 숫자끼리 곱함.
  * `A @ B`: 가로줄과 세로줄을 곱해서 더함 (신경망 연산의 기본).

## 🧭 [3단계. 기계학습(머신러닝)은 어떻게 공부하고 채점할까?]
* **학습의 3대 유형:**
  * 지도학습 (회귀: 연속 숫자 예측 / 분류: 선택지 판별)
  * 비지도학습 (정답 없이 군집화)
  * 강화학습 (보상을 극대화하는 행동 정책 터득)
* **과적합(Overfitting):** 연습 문제 답만 통째로 외워서 새로운 시험 문제(테스트 데이터)를 다 틀리는 현상.
* **🚨 왜 정확도 하나만으로 안 될까? (시험 1순위):**
  * **재현율 (Recall):** 암 환자 진단처럼 정답을 놓치면 치명적인 곳에 필수.
  * **정밀도 (Precision):** 스팸 메일함처럼 정상 메일을 스팸으로 지우면 안 되는 곳에 필수.

## 🧭 [4단계. 인공 신경망의 뇌세포(퍼셉트론)는 어떻게 생각할까?]
* **퍼셉트론의 원리:** 각 질문에 중요도(가중치 $w$)를 곱하고 기준 점수(편향 $b$)를 넘으면 1, 못 넘으면 0을 출력.
* **XOR 문제와 다층 퍼셉트론:** 뇌세포 1개는 직선 하나밖에 못 그어 XOR 문제를 못 풂 ➡️ 층을 여러 개 쌓고(은닉층) 곡선 형태의 비선형 활성화 함수를 도입해 해결.
* **왜 시그모이드 대신 ReLU를 쓸까?** 시그모이드는 층이 깊어지면 미분값이 0이 되는 **기울기 소실(Vanishing Gradient)**이 생기지만, ReLU는 0 초과에서 그대로 통과시켜 학습이 멈추지 않음.
* **오류 역전파 (Backpropagation):** 오답이 나왔을 때 뒤에서부터 앞으로 오차를 거꾸로 전파하며 원인을 제공한 가중치를 고치는 과정.

## 🧭 [5단계. 실전 딥러닝과 시각 인공지능 (CNN)]
* **CNN을 쓰는 이유:** 이미지를 1줄로 펴면 상하좌우 위치 관계(공간 정보)가 깨지므로, **작은 돋보기(필터)로 훑으며 모서리/형태 특징을 보존**.
* **CNN 레이어 비교:**
  * `Conv2D`: 필터를 이동하며 특징 맵 추출 (가중치 학습 있음).
  * `MaxPooling2D`: 가장 큰 값만 남겨 크기를 절반으로 축소 (**가중치 학습 없음**).
* **옵티마이저 원픽:** `Adam` (속도 관성 + 보폭 조절 결합).
* **과적합 방지 4대장:** 드롭아웃(Dropout), 데이터 증강(Augmentation), 가중치 규제(L1/L2), 조기 종료(Early Stopping).

## 🧭 [6단계. 생성 모델과 시험 7대 족보]
* **오토인코더:** 큰 사진을 핵심 요약본(잠재 공간)으로 압축했다가 복원 (노이즈 제거, 이상치 탐지).
* **GAN:** 위조지폐범(생성자)과 경찰(판별자)이 서로 경쟁하며 초고화질 가짜 이미지를 생성.
* **🎯 시험장 7대 정답 공식:**
  1. XOR 문제 ➡️ 다층 퍼셉트론(MLP)으로 해결.
  2. 기울기 소실 ➡️ ReLU 활성화 함수로 해결.
  3. 기본 추천 옵티마이저 ➡️ Adam.
  4. CNN 풀링 ➡️ 가중치 학습 없이 크기만 축소.
  5. 암 진단 평가 ➡️ 재현율(Recall)이 핵심.
  6. 스팸 메일 필터 ➡️ 정밀도(Precision)가 핵심.
  7. 손실 함수 매칭 ➡️ 이진은 `binary_crossentropy`, 다중은 `sparse_categorical_crossentropy`.
