## 💡 핵심 요약 (Level 0)
1. **네이티브 1-bit의 등장 (Bonsai 27B)**: PrismML이라는 스타트업이 Qwen 3.6 27B를 기반으로 **'처음부터 1-bit(또는 1.58-bit Ternary)로 설계 및 학습된'** Bonsai 27B 모델을 출시함. 용량은 단 3.9GB에 불과해 스마트폰이나 8GB VRAM에 완벽히 들어감.
2. **사후 양자화(PTQ)와의 차별점**: 멀쩡한 고정밀도 모델을 나중에 1-bit로 억지로 짓눌러 뇌손상(환각)을 일으키는 사후 양자화(Post-Training Quantization)와 달리, 태생부터 1-bit로 학습되었기 때문에 원본 27B 모델 지능의 90~95%를 보존함.
3. **KV 캐시의 역습 (컨텍스트 함정)**: 모델 용량이 3.9GB라 8GB VRAM에 널널할 것 같지만, 컨텍스트 윈도우를 100,000 토큰으로 늘리자 KV 캐시가 폭발하며 총 12GB의 VRAM을 먹어치움. 8GB 유저는 모델이 가볍더라도 컨텍스트 창을 8K~16K 수준으로 제한해야 함.

## 📜 상세 분석 및 타임스탬프 근거 (Level 1 Claims)

### 1. 27B 체급의 3.9GB 다이어트 [02:25~04:38]
- Qwen 3.6 27B의 원본(FP16) 용량은 약 50GB에 달함. 이를 구동하려면 최소 24GB~32GB의 VRAM이 필요함.
- PrismML의 'Bonsai 27B'는 1-bit 아키텍처를 채택하여 모델 가중치 용량을 3.9GB로 극단적으로 줄임 (2-bit 버전인 Ternary Bonsai는 5.9GB).
- **기술적 핵심**: 기존 LM Studio에서 받던 'Q1_S' 같은 포맷은 큰 모델을 작게 압축(Compression)한 것이지만, Bonsai는 처음부터 1-bit로 디자인(Designed from the beginning)된 네이티브 모델임.

### 2. 성능 테스트 (지능 보존) [08:30~11:47]
- **스트로베리 테스트**: "Strawberry에 r이 몇 개인가?" -> 3개라고 즉시 정확히 답변 (사후 양자화 1-bit 모델들이 흔히 틀리는 문제).
- **함정 문제 (실패)**: "차를 세차하려고 하는데 세차장이 50m 앞이다. 걸어갈까 차를 탈까?" -> "50m면 걸어가는 게 낫다"며 세차라는 목적을 잊어버리는 한계 노출.
- **비전 테스트**: 우주 왕복선을 업고 있는 NASA 보잉 747기 사진을 보고 비행기 대수(4대) 및 각각의 기종(F-15, 셔틀 등)을 정확히 인식함.

### 3. 컨텍스트 윈도우와 메모리 폭발 [12:51~13:50]
- 웹 검색 도구를 사용하기 위해 컨텍스트 길이를 8,000에서 100,000 토큰으로 늘림.
- 작업 관리자 확인 결과, VRAM 사용량이 순식간에 5.8GB에서 **12GB**로 두 배 이상 폭등함.
- **결론**: 모델 가중치 용량(3.9GB)은 뼈대일 뿐, 입력값이 길어지면 생성되는 KV 캐시 메모리는 1-bit 모델이든 16-bit 모델이든 동일하게 팽창함. 8GB 유저는 1-bit 모델을 쓰더라도 16K 이상의 대형 문서를 넣으면 시스템 RAM 스왑이 발생함.

## 🛠️ AI(나) 및 3-PC 사용자 환경 적용점 (Level 2 System Actions)

1. **메인 데스크톱 (PC B: RX 6600 8GB)의 1-bit 거부 정책 예외 처리 (ADR 수정)**:
   - 기존의 [[8GB_VRAM_모델_선택_및_오프로딩_원칙_ADR]]에서 "1-bit 양자화는 뇌손상(환각)을 일으키므로 전면 금지한다"고 못 박았음.
   - **예외 조항 신설**: 단, 이 비디오에서 소개된 Bonsai 27B(또는 BitNet 계열)와 같이 **'태생적 네이티브 1-bit 아키텍처(Native 1-bit)'** 모델에 한해서는 8GB VRAM 내 구동을 허가함. 지능 손실이 적고 VRAM에 100% 적재되어 광속 추론이 가능하기 때문임.
2. **KV 캐시 폭발 가드레일 마련**:
   - 네이티브 1-bit 모델을 쓰더라도, 컨텍스트를 32K 이상으로 잡으면 VRAM 8GB를 초과해 끔찍한 스와핑이 발생함.
   - **라우팅 규칙 갱신**: 네이티브 1-bit 모델은 '빠른 단발성 코딩 및 웹 검색' 용도로만 사용(최대 16K 컨텍스트 제한)하며, 수만 단어의 대형 문서를 읽어야 할 때는 여전히 기존 룰대로 **35B MoE Q4 + KV 캐시 양자화 + CPU 오프로딩** 전략을 고수함.
