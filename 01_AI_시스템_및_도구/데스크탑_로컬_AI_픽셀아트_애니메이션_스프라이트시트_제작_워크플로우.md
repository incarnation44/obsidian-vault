## 💡 핵심 3줄 요약
1. 데스크탑 로컬 AI 환경을 활용해 단일 픽셀 캐릭터 이미지로부터 걷기 등 모션 비디오를 생성하고, 이를 프레임 단위로 분할하여 **스프라이트 시트(Sprite Sheet)**를 자동 생성함.
2. 수작업 도트 노가다나 그래픽 후보정 없이, 생성된 스프라이트 시트를 유니티(Unity) 등 게임 엔진에 즉시 드래그앤드롭하여 동작하는 2D 애니메이션 클립으로 변환함.
3. 약 78초 내외의 빠른 로컬 렌더링과 해상도 스케일 조정을 통해 상용 게임 수준의 2D 캐릭터 에셋을 무제한 무료로 양산 가능함.

## 📌 주요 제작 파이프라인 단계

```mermaid
graph LR
    A[픽셀 캐릭터 생성/입력] --> B[모션 비디오 생성]
    B --> C[프레임 분할 & 스프라이트 시트 결합]
    C --> D[유니티/엔진 임포트 & 애니메이션 클립 생성]
    D --> E[캐릭터 이동/동작 코딩 완성]
```

1. **캐릭터 베이스 생성**: 프롬프트 또는 베이스 이미지를 입력하여 일관된 도트 스타일 캐릭터 생성.
2. **모션 애니메이션 렌더링**: '걷기(Walking)', '공격(Attack)', '점프(Jump)' 등 프롬프트를 지정하여 수 초간의 모션 영상 추출.
3. **스프라이트 시트(Sprite Sheet) 자동 추출**: 영상의 각 프레임을 그리드 형태의 투명 PNG 스프라이트 시트로 일괄 패킹.
4. **엔진 연동 (유니티/웹)**: 스프라이트 시트 슬라이스 후 애니메이션 컨트롤러에 연결하여 실제 이동 모션 검증.
5. **업스케일 & 리파인**: 해상도 및 디테일 부족 시 로컬 스케일러로 재렌더링 (후보정 없이 78초 만에 고품질 에셋 확보).

## 🛠️ AI(나)에게 적용할 점 (Antigravity & 전일도 워크플로우 적용 전략)

### 1. 2D 웹 게임 & 인터랙티브 웹 UI 스프라이트 자동화
* Antigravity가 웹 애플리케이션 개발 시 단순 정적 디자인을 넘어 **HTML5 Canvas, Phaser.js, CSS Keyframe 기반 2D 스프라이트 애니메이션**을 즉시 탑재할 수 있는 파이프라인을 구축한다.
* 에셋이 필요할 때 `generate_image`로 생성한 원본 캐릭터를 CSS 스프라이트 시트 그리드 코드로 자동 분할 및 재생하는 컴포넌트를 즉시 코딩한다.

### 2. 로컬 하드웨어(RX 6600 8GB VRAM) 최적화 에셋 양산 연계
* 사용자 시스템 사양(RX 6600 8GB)에 맞춰, 고비용 클라우드 API 결제 없이 로컬 ComfyUI / SD / AnimateDiff 경량 모델을 통한 무제한 2D 에셋 생성 워크플로우를 보조한다.
* 미디어 에셋은 헌법 원칙에 따라 메인 C: 드라이브 대신 **보조 드라이브(`D:\사진`, `D:\개인자료`)**로 분기 저장하도록 경로를 표준화한다.

### 3. 바이브 코딩(Vibe Coding) 기반 1인 게임/프로덕트 쾌속 제작 지원
* 캐릭터 에셋 생성부터 스프라이트 연동, 상태 머신(FSM) 및 조작 스크립트 작성까지 에이전트가 원스톱으로 빌드하여 1인 인디 게임 개발의 병목인 '도트 애니메이션 제작' 허들을 완전히 제거한다.
