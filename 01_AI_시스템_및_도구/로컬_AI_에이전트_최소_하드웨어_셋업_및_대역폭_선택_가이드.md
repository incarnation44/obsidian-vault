## 💡 핵심 요약
1. **용량(Capacity) vs 대역폭(Bandwidth) 2대 법칙**: VRAM 용량은 '어떤 모델을 올릴 수 있는가(카운터 면적)'를 결정하고, 메모리 대역폭(GB/s)은 '추론 속도(요리사의 발걸음 속도, tps)'를 결정한다.
2. **컨텍스트 메모리(KV 캐시) 함정 & MoE 혁신**: 32B 모델이 24GB VRAM에 딱 맞게 적재되더라도 에이전트의 긴 대화/컨텍스트가 진행되면 여유 메모리가 고갈된다. 반면 소형 활성 파라미터 기반 MoE 모델의 발전으로 12GB~17GB 수준에서도 실전 에이전트 구동이 가능해졌다.
3. **티어별 현실적 하드웨어 추천**: $1,000 미만 입문은 Intel Arc B580(12GB) + 32GB RAM, $2,000~$3,500 실전 메인스트림은 빠른 코딩 루프를 위한 듀얼 중고 RTX 3090(48GB VRAM) 또는 야간 대용량 문서 분석을 위한 Strix Halo(128GB 통합 메모리) 미니 PC로 분기한다.

## 🍳 주방 메타포로 이해하는 로컬 AI 하드웨어

| 개념 | 주방 비유 | 결정 요소 | 비고 |
| :--- | :--- | :--- | :--- |
| **모델 (Model)** | 레시피 북 | 파라미터 크기 | 크기가 클수록 정교하지만 많은 자원 요구 |
| **메모리 용량 (Capacity)** | 조리대(카운터) 면적 | **무엇을 돌릴 수 있는가 (What)** | 모델 가중치 + 긴 컨텍스트 KV 캐시 수용 |
| **메모리 대역폭 (Bandwidth)** | 요리사의 이동 속도 | **얼마나 빠른가 (How fast / tps)** | LLM 추론은 메모리 바운드 작업 |

- 카운터가 커도 요리사가 느리면 큰 책을 올려놓고 하염없이 기다려야 함 (통합 메모리 Mac/Strix Halo의 특성).
- 카운터가 작아도 요리사가 전력 질주하면 레시피가 올라가는 한 압도적인 속도를 냄 (RTX 3090/5090 GPU 특성).

## 🔍 이전 가이드 핵심 오류 수정 및 팩트 정리

1. **Apple Silicon 포맷**: Mac 사용자는 GGML 대신 네이티브 **MLX** 형식을 사용할 때 20~80% 속도 향상.
2. **시스템 RAM 거품 제거**: 모델을 GPU VRAM에 100% 올려서 구동한다면 시스템 RAM 64GB는 낭비이며, RAM 가격이 3~4배 급등한 현 시장에서는 32GB로 충분함.
3. **컨텍스트 헤드룸 계산**: 모델 크기만 계산해 24GB VRAM에 32B 모델을 꽉 채우면, 긴 에이전트 루프 구동 시 KV 캐시가 VRAM을 잠식해 OOM(메모리 부족)이나 심각한 속도 저하 발생.

## 🏗️ 2026 티어별 하드웨어 빌드 가이드

### Tier 1: 초가성비 입문 ($1,000 내외)
- **핵심 구성**: **Intel Arc B580 12GB** (약 $350, 신품 12GB 중 최저가) + 중고 CPU + **32GB RAM**
- **특징**: MoE 모델과 결합해 외부 클라우드 전송 없는 완전 프라이빗 문서 분석 및 텍스트 초안 작성 가능.

### Tier 2: 실전 메인스트림 ($2,000 ~ $3,500) - 2가지 경로
- **경로 A (스프린팅 쿡 / 코딩 에이전트 특화)**:
  - **구성**: 중고 **RTX 3090 2장 (총 48GB VRAM)**
  - **대역폭**: 936 GB/s (압도적 속도)
  - **성능**: 텐서 병렬화(Tensor Parallelism) 적용 시 24B 코딩 모델 170k 컨텍스트에서 40 tps -> 80 tps 달성.
  - **적합 대상**: 빠른 피드백 루프가 필요한 코딩 에이전트 및 즉각적인 대화형 워크플로우.
- **경로 B (대형 카운터 / 대용량 연구 분석 특화)**:
  - **구성**: **AMD Strix Halo 미니 PC (128GB 통합 메모리)** (Minisforum, Framework 등) 또는 중고 Mac Studio
  - **대역폭**: 약 256 GB/s (3090의 1/4 속도)
  - **성능**: 100GB급 초대형 모델 적재 가능.
  - **적합 대상**: 밤새 대용량 문서/도서/논문을 분석하는 RAG 에이전트.

### Tier 3: 하이엔드 ($5,000 이상) - 관망 권장
- **M3 Ultra Mac Studio**: 819 GB/s 대역폭, 최대 512GB 통합 메모리 (초대형 모델 적재 끝판왕).
- **엔비디아 DGX Spark**: 128GB 메모리이나 대역폭 273 GB/s로 속도가 아닌 CUDA 생태계 목적.
- **RTX 6000 Ada (96GB)**: $14,000~$16,000로 가격 폭등하여 일반 사용에는 부적합.

## 🛠️ AI(Antigravity) 시스템 및 사용자 환경 적용점

### 1. 사용자 시스템 팩트 대조 및 최적화
- **현재 PC 사양**: AMD Ryzen 5 5600XT / **Radeon RX 6600 (8GB VRAM)** / **32GB RAM**
- **구동 최적화 전략**:
  - 8GB VRAM에 완벽히 상주하는 `qwen2.5:7b`(44.72 tps) 및 `deepseek-r1:8b`(38.64 tps) 설정은 VRAM 대역폭을 100% 뽑아내는 최적의 구성임.
  - 긴 대화 시 KV 캐시가 VRAM 한계를 넘어 시스템 RAM으로 오프로드되면 tps가 급락하므로, `chunkless-rag` 및 컨텍스트 엔지니어링(W-S-C-I 프로토콜)을 가동해 컨텍스트 윈도우를 상시 컴팩트하게 유지함.

### 2. 하드웨어 확장 로드맵 수립
- 향후 로컬 에이전트 단독 구동 성능 확장이 필요할 경우:
  - 코딩 에이전트 가속 목적: 중고 RTX 3090 (24GB VRAM) 영입이 가장 가성비 높은 선택지.
  - 대용량 지식 분석 목적: 128GB 통합 메모리 Strix Halo 미니 PC를 보조 노드로 배치하는 아키텍처 권장.
