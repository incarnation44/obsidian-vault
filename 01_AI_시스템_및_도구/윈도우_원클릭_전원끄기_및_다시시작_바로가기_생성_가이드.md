# 🔘 윈도우 원클릭 [끄기] & [다시 시작] 바로가기 제작 가이드

> 다른 PC(노트북 등)에서도 바탕화면에 클릭 한 번으로 꺼지거나 재부팅되는 버튼을 만드는 방법입니다.

---

## 1. 🔴 [끄기] 버튼 만들기

1. **바탕화면 빈 곳 우클릭** ➔ **[새로 만들기]** ➔ **[바로 가기]** 클릭
2. **항목 위치 입력창**에 아래 명령어 복사 붙여넣기:
   `	ext
   shutdown.exe -s -t 0
   `
3. 바로가기 이름: **끄기** 입력 후 완료
4. **빨간 전원 아이콘 변경**:
   - 생성된 바로가기 **우클릭** ➔ **[속성]**
   - **[아이콘 변경]** 클릭
   - 찾아보기 창에 %SystemRoot%\System32\SHELL32.dll 입력 후 엔터
   - 목록에서 **빨간색 전원 버튼 모양 아이콘** 선택 후 확인

---

## 2. 🟢 [다시 시작] 버튼 만들기

1. **바탕화면 빈 곳 우클릭** ➔ **[새로 만들기]** ➔ **[바로 가기]** 클릭
2. **항목 위치 입력창**에 아래 명령어 복사 붙여넣기:
   `	ext
   shutdown.exe -r -t 0
   `
3. 바로가기 이름: **다시 시작** 입력 후 완료
4. **초록 전원 아이콘 변경**:
   - 생성된 바로가기 **우클릭** ➔ **[속성]**
   - **[아이콘 변경]** ➔ **[찾아보기]** 클릭
   - 옵시디언 볼트에 동기화된 C:\전일도\scripts\icons\restart_green.ico 선택 후 확인  
     *(또는 윈도우 기본 %SystemRoot%\System32\imageres.dll 의 녹색 회전 아이콘 선택)*

---

## ⚡ 3. 1초 자동 생성 (PowerShell 복붙용 원클릭 코드)

다른 PC에서 PowerShell을 열고 아래 코드를 그대로 붙여넣으면 즉시 2개 버튼이 바탕화면에 생성됩니다:

`powershell
 = New-Object -ComObject WScript.Shell
 = [Environment]::GetFolderPath('Desktop')

# 1. 끄기 바로가기 생성 (빨간색)
 = Join-Path  '끄기.lnk'
 = .CreateShortcut()
.TargetPath = 'C:\Windows\System32\shutdown.exe'
.Arguments = '-s -t 0'
.IconLocation = '%SystemRoot%\System32\SHELL32.dll,27'
.Save()

# 2. 다시 시작 바로가기 생성 (초록색)
 = Join-Path  '다시 시작.lnk'
 = .CreateShortcut()
.TargetPath = 'C:\Windows\System32\shutdown.exe'
.Arguments = '-r -t 0'
.IconLocation = 'C:\전일도\scripts\iconsestart_green.ico,0'
.Save()

Write-Host '바탕화면에 끄기 / 다시 시작 바로가기 생성 완료!' -ForegroundColor Green
`
