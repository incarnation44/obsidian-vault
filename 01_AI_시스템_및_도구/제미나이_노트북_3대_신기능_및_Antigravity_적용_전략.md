## 💡 핵심 3줄 요약

1. **채팅창에서 커스텀 파일 생성**: 우측 고정 버튼 대신 채팅창에서 자연어로 지출 원형 차트(PNG), 엑셀, 워드, PPT 초안을 내 자료 100% 기반으로 정밀 추출 생성.
2. **부족한 정보 자동 웹 탐색(Gap-Filling)**: 업로드한 내 사업/공고 문서의 빈틈을 스스로 진단한 뒤 외부 웹에서 내 조건(업력, 업종 등)에 맞는 최적 공고를 자동 발굴.
3. **소스 자동 라벨링 & 포커스 필터링**: 수십 개 섞인 문서를 클릭 한 번으로 4대 주제 그룹으로 묶고, 필요한 묶음만 켜서 겉핥기 답변을 없애고 세부 심층 정보를 완벽 추출.

---

## 📌 주요 내용 및 핵심 포인트

### 1. 채팅창 파일 직접 생성 (Generative Artifact Creation)
- 기존 스튜디오 버튼의 제한을 넘어 채팅창 프롬프트로 복잡한 결과물 생성 가능.
- **카페 장부 시나리오**: 여러 연도의 분산된 매출/원가/고정비 CSV 데이터를 통째로 넣고, 항목별 비중 원형 차트(PNG)를 채팅창 명령으로 즉시 생성.
- **정확도 극대화 팁**: 
  - 1차는 영문으로 생성하여 텍스트 깨짐/중복 방지
  - 확정된 수치와 차트 이미지를 Gemini의 **확장된 사고(Thinking)** 모델에 넘겨 고품질 한국어 그래픽 완성.
  - 내 원본 데이터 범위 안에서만 계산하므로 할루시네이션 없는 안전한 초안 확보.

### 2. 소스 찾아오기 (웹 탐색 결손 보강)
- 기존의 폐쇄형(업로드 문서만 참조) RAG 한계 탈피.
- 지원사업 공고 3개와 내 사업 정보 문서를 넣으면, 신청 가능 여부(업력 3년 미만 등 불가 사유)를 대조 판정.
- 내 조건에서 부족한 영역(예: 상세페이지 제작 지원)을 AI가 먼저 진단하고, 웹에서 조건(여성 대표, 1인 제조 등)에 딱 맞는 최신 지원사업을 자동 검색해 소스로 추가.

### 3. 소스 자동 라벨링 (Cluster-Focused RAG)
- 자료가 많아지면 모든 문서를 얕게 훑느라 핵심 정보(신청 방법, 환급 절차 등)가 누락되는 문제 해결.
- **자동 라벨** 기능으로 근무/휴가, 급여/정산, 복리후생, 운영/보안 등 주제별 자동 클러스터링.
- 특정 그룹(예: 복리후생)만 체크하여 불필요한 컨텍스트 노이즈를 차단하면, 같은 문서에서도 세부 조건과 금액까지 완벽하게 추출.

## 🛠️ AI(나: Antigravity)에게 적용할 점

1. **선택적 컨텍스트 격리(Selective Context Isolation)**:
   - Antigravity RAG 검색 및 지식 처리 시, 모든 옵시디언/코드 문서를 무차별 주입하지 않고 질문 도메인에 맞는 서브셋 클러스터만 활성화하여 심층 추론 품질 향상.
2. **사전 결손 진단형 웹 브라우징(Gap-Driven Browsing Protocol)**:
   - 사용자 지시 수행 시 로컬 문서의 제약 조건을 먼저 파악하고, 누락된 파라미터나 외부 최신 데이터가 필요할 때만 타깃형 검색을 발동하는 스마트 검색 워크플로우 적용.
3. **2단계 팩트 검증 시각화(2-Step Verified Artifact)**:
   - 데이터 분석/차트 작성 시 1단계에서 수치 무결성을 확정한 뒤, 2단계에서 고품질 포맷으로 가공하는 이중화 파이프라인 정착.
