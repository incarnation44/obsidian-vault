## 클래스 (시험에 나오는 한 줄)
클래스는 붕어빵 틀, 객체는 찍어낸 붕어빵. `self` 는 그 붕어빵 자신.

```python
class Cat:
    def __init__(self, name):
        self.name = name
    def meow(self):
        return f"{self.name}: 야옹"
```

## 자주 헷갈리는 것
- `input()` 은 **문자열**. 숫자 계산 전에 `int(...)`.
- `+` 는 숫자면 덧셈, 문자열이면 이어붙이기 (연산자 오버로딩).
- `#` 주석은 실행되지 않는다.
- 코랩 = 브라우저 실험실, 스탠드얼론 = 내 PC에 설치.
