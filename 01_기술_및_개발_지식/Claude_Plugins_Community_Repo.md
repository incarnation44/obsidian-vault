## 📌 주요 내용 및 타임라인 포인트
- **Claude 플러그인 커뮤니티 저장소**:
  - Claude Code, Claude Co-work 등에서 바로 사용할 수 있는 2,200개 이상의 유용한 플러그인이 모여 있는 공식/커뮤니티 저장소입니다.
- **웹사이트 대신 GitHub 저장소가 존재하는 이유**:
  - 웹사이트는 사람이 직접 스크롤하며 찾기에는 좋지만, AI가 검색하기에는 비효율적입니다.
  - 저장소(Repo) 형태는 정보가 고도로 압축되어 있어, 사용자가 "내 강아지 가계부 관리를 위한 플러그인 찾아줘"라고 Claude에게 명령했을 때, AI가 저장소를 빠르게 뒤져서 즉각적으로 찾아낼 수 있도록 설계되었습니다.
- **플러그인 보안의 중요성 (Security Scanned)**:
  - 플러그인은 컴퓨터 내에서 스크립트와 소프트웨어를 직접 실행(Run)하므로, 출처를 모르는 플러그인을 설치하는 것은 해킹이나 정보 탈취의 위험이 큽니다.
  - 이 저장소에 등록된 플러그인들은 **보안 스캔(Security scanned)**을 거쳤기 때문에, 사용자들이 악성 코드나 비밀번호 탈취 걱정 없이 안전하게 자신의 AI 에이전트에 연결하여 사용할 수 있습니다.
