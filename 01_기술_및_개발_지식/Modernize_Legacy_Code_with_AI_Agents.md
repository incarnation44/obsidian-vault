## 💡 핵심 요약
문서도 없고 데이터 흐름도 복잡하며 테스트 코드조차 없는 '레거시 코드베이스(오래된 기존 코드)'를 AI 코딩 에이전트를 활용해 안전하고 효율적으로 현대화(Modernize)하는 전략적 접근법을 소개하는 가이드입니다.

## 📌 주요 내용 및 타임라인 포인트
- **레거시 코드에서 AI의 강력함 (데이터 추적)**:
  - AI 에이전트는 복잡한 시스템 전반에 걸친 데이터 추적에 매우 뛰어납니다. 예를 들어, 프론트엔드에서 특정 필드를 필수값으로 변경하면 AI가 API부터 데이터베이스 레이어까지 전체 경로를 역추적하여 관련된 모든 코드를 일괄 수정할 수 있습니다.
- **점진적 접근법 (Change-Request-Driven Approach)**:
  - 방대하고 낯선 레거시 코드를 처음부터 다 이해하려고 하지 마세요. '변경 요청(Change Request)'이 발생할 때마다 해당 블록(Block)만 유기적으로 학습하며 접근하는 것이 핵심입니다.
- **현대화 3단계: 계획(Plan) ➔ 실행(Execute) ➔ 검증(Verify)**:
  - **[Plan] 가장 중요한 골든 룰(Golden Rule)**: 작업을 시작하기 전 샌드박스를 준비하고, 컴파일러, 린터, 유닛 테스트 등 **'로컬 실행 방법'을 `readme` 문서에 정확히 기록**해 두어야 합니다.
  - **실시간 자가 치유(Auto-Correct)**: AI 에이전트가 로컬 툴을 실행하는 방법을 인지하게 되면(readme 참조), 수십 가지의 코드 변경을 스스로 시도하고 ➔ 테스트를 실행하고 ➔ 문법 에러를 포착하여 ➔ 사람의 개입 없이 **실시간으로 코드를 자가 수정(Auto-correct)**하는 강력한 피드백 루프가 완성됩니다.
