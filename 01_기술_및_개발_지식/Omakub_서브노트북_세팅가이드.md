# 💻 Omakub: 서브 노트북(Dell 7440) 완벽 부활 세팅 가이드

## 📌 Omakub란?
루비 온 레일즈(Ruby on Rails)의 창시자인 DHH가 만든 **'리눅스 우분투용 자동 세팅 스크립트'**입니다. 
복잡하고 투박한 리눅스를 마치 맥(Mac)처럼 예쁘고 완벽한 개발 환경으로 단 한 줄의 명령어로 세팅해 줍니다.
* 윈도우 11이 버거운 구형 노트북이나 서브 노트북(Dell Latitude 7440)을 강력하고 가벼운 전용 코딩 머신으로 부활시킬 때 최적입니다.

## 🚀 노트북에 적용하는 방법 (How to apply)

1. **우분투(Ubuntu 24.04 LTS) 설치**
   - 서브 노트북을 포맷하고 기본 Ubuntu 24.04 LTS를 설치합니다. (또는 WSL2 환경에서도 일부 호환 가능)
2. **Omakub 자동 설치 스크립트 실행**
   - 터미널을 열고 아래 명령어를 그대로 복사해서 붙여넣습니다.
   ```bash
   wget -qO- https://omakub.org/install | bash
   ```
3. **완료 및 재부팅**
   - 스크립트가 모든 개발 도구(Docker, VS Code, 터미널 테마, 단축키 등)를 알아서 다운받고 예쁘게 꾸며줍니다. 재부팅 후 바로 사용하시면 됩니다.

> [!TIP]
> **주의사항**: Omakub는 기본적으로 'Vanilla Ubuntu(아무것도 안 깔린 순정 우분투)' 환경을 전제로 만들어졌습니다. 기존에 사용 중인 파일이 있는 상태에서 덮어씌우기보다는, 노트북을 밀고 새로 세팅하실 때 쓰시는 것을 권장합니다.
