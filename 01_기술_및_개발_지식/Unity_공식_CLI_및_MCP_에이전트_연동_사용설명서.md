# 🎬 Unity CLI MCP 사용설명서 (Unity Korea)

## 💡 핵심 3줄 요약
1. **Unity CLI 공식 출시**: 기존 마우스/위지윅 GUI 중심의 유니티 에디터를 넘어, 터미널 및 AI 에이전트가 헤드리스(Headless) 환경에서 직접 프로젝트, 에디터 버전, 패키지, 빌드를 제어할 수 있는 공식 Unity CLI가 공개되었다.
2. **Claude Desktop Skills & Unity MCP 연동**: 유니티 CLI 전용 스킬을 Claude 등 LLM에 주입하고 프로젝트에 `unity pipeline` 패키지를 설치하면, 에디터 내부에 MCP(Model Context Protocol) 서버가 가동되어 AI와 에디터 간 양방향 실시간 제어가 확립된다.
3. **인에디터 자연어 개발(대딸깍 시대)**: 마우스 조작 없이 "씬 상태 점검해줘", "중앙에 큐브 생성하고 머티리얼 변경해줘"라는 자연어 프롬프트만으로 AI가 씬 내부 하이어라키를 탐색하고 오브젝트를 실시간 생성·수정·저장하는 워크플로우가 구현되었다.

## 📌 주요 내용 및 타임스탬프 포인트
- **[00:00 ~ 03:30] CLI 도입 배경과 개발 워크플로우의 확장**:
  - 도스(DOS), 리눅스 등 저수준 시스템 제어의 근간이었던 CLI의 장점을 유니티 엔진에 본격 도입.
  - GUI는 사람 친화적이지만 반복 자동화나 원격 에이전트 제어에는 병목이 발생하므로, 컴퓨터·스크립트 친화적인 Unity CLI 공식 배포 시작.
- **[03:30 ~ 09:30] Unity CLI 설치 및 환경 구성**:
  - 공식 문서(`Use the Unity Command Line Interface`) 기반 설치.
  - Unity Hub 도구 상자 또는 터미널에서 CLI 환경 설정 및 버전(`unity --version`), 에디터 리스트(`unity editor list`) 탐색.
- **[09:30 ~ 17:00] 프로젝트 및 패키지 헤드리스 제어**:
  - 템플릿 리스트(`unity template list`) 확인 후 에디터를 직접 띄우지 않고도 커맨드 라인에서 백그라운드 프로젝트 생성 및 패키지 설치(`unity package install`) 가능.
  - 빌드 파이프라인 및 CI/CD 자동화 연동의 토대 마련.
- **[17:00 ~ 24:00] AI 에이전트(Claude Desktop)와 Unity CLI Skills 주입**:
  - Claude Desktop의 스킬(Skills) 기능을 통해 Unity CLI 문법과 파라미터 지식을 에이전트에 주입 (NPX 또는 스킬 폴더 업로드 방식 지원).
  - 에이전트가 "프로젝트 열어줘", "패키지 점검해줘"라는 자연어를 해석해 유니티 CLI 명령을 자율 실행.
- **[24:00 ~ 27:00] Unity Pipeline 패키지와 MCP 서버 가동**:
  - 프로젝트 내 `unity pipeline install` 실행 시 에디터 내부에 전용 MCP(Model Context Protocol) 서버 백엔드 구축.
  - `unity status`로 서버 가동 확인 후 LLM 클라이언트와 실시간 양방향 프로토콜 연결.
- **[27:00 ~ 32:00] 대화형 인에디터 실시간 개발 시연 ("대딸깍 시대")**:
  - 씬 상태 점검: AI가 씬 내부 오브젝트, 트랜스폼, 컴포넌트 목록을 실시간 인출.
  - 오브젝트 자율 생성: 자연어 지시로 씬 정중앙에 큐브 생성, 스케일 및 위치 조정, 머티리얼 적용, 씬 자동 저장까지 완결.

## 🛠️ AI(나)에게 적용할 점
- **에이전트 제어 관점의 도구 계약 표준화 (Agent-Ready CLI/MCP)**:
  - Unity의 이번 접근은 Antigravity가 지향하는 WebMCP 및 로컬 툴 하네스와 정확히 일치함. GUI 전용 툴이라도 백그라운드 CLI 또는 MCP 인터페이스를 확보하면 에이전트가 사람 대신 정밀한 하위 작업을 완결할 수 있음.
  - 향후 유니티나 3D/그래픽 관련 작업 시 GUI 캡처(Vision)에 의존하는 비효율을 버리고, Unity CLI 및 Unity MCP 도구를 직접 연동하여 헤드리스로 제어하는 패턴을 우선 채택함.
- **권한 관리 가이드**:
  - 영상에서 언급된 대로 CLI 도구 연동 시 매 명령마다 확인 팝업을 띄우면 에이전틱 워크플로우가 완전히 마비됨. Antigravity의 자율 실행 권한 원칙과 안전 가드레일(6대 불가침)의 균형이 왜 필수적인지 실증적 레퍼런스로 활용.
