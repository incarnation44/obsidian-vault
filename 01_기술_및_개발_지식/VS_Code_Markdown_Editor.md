## 💡 핵심 요약
VS Code의 최신 버전에 새롭게 추가된 **마크다운 에디터** 기능으로, 미리보기(Preview) 화면 내에서 직접 텍스트를 수정(WYSIWYG)하고 실시간으로 마크다운 문법이 자동 반영되도록 지원합니다.

## 📌 주요 내용 및 기능 사용법
- **기존 마크다운 편집 방식**:
  - `Ctrl + Shift + V`: 마크다운 미리보기 화면과 에디터 간의 전환.
  - 측면 분할 기능: 우측 상단 버튼을 클릭해 좌측 코드, 우측 미리보기 분할 화면 구성 (동기화 스크롤 지원).
- **🌟 새로운 마크다운 에디터 (New Markdown Editor)**:
  - **접근 방법**: 우측 상단 `...` (더보기) 메뉴 ➔ `Reopen editor with` ➔ `Markdown editor` 선택.
  - **주요 장점**: 마크다운 소스코드를 보지 않고도, **미리보기 화면 자체에서 문서를 잠금 해제(Unlock)하여 직접 텍스트를 수정**할 수 있습니다. 수정 내용은 올바른 마크다운 문법으로 원본 소스 파일에 실시간 자동 업데이트됩니다.
- **AI 에이전트 연동 (`Open in agents`)**:
  - 에디터 상단의 'Open in agents' 버튼을 클릭해 에이전트 창을 열고 프로젝트 폴더의 파일들을 보며 AI와 함께 마크다운 문서를 작성할 수 있습니다.
