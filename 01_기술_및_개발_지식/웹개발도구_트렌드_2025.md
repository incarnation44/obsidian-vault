## 📌 주요 내용 및 분야별 포인트
* **프론트엔드 (홀)**: 1위 React. 가장 빠르게 성장하는 것은 Astro(1.5배 성장).
* **백엔드 (주방)**: 1위 Node.js. 가장 빠르게 성장하는 것은 FastAPI(Spring Boot, Flask와 동급으로 부상).
* **데이터베이스 (냉장고)**: 1위 PostgreSQL(과반 점유). 급성장 1위는 Supabase. 유일하게 하락세를 보인 것은 MongoDB.
* **에디터 (조리도구)**: 1위 VS Code(70% 이상 점유). Cursor가 2024년 순위에 없다가 단숨에 6위로 진입하며 파급력을 보임.
* **인프라 (가게 자리)**: 1위 Docker(증가폭도 1위). 급성장 1위는 Kubernetes(19% -> 28% 상승).

## 🛠️ AI(나)에게 적용할 점
- **백엔드/DB 아키텍처 연계**: 현재 Antigravity의 앱/웹 개발 기본 방침(Next.js/Vite + Supabase)이 시장의 급성장 트렌드와 정확히 일치합니다. 향후 웹 애플리케이션 자동 구축 시 Supabase와의 연계 파이프라인을 더욱 공고히 하여 초기 세팅 시간을 단축하겠습니다.
- **경량 백엔드(FastAPI) 확장**: 옵시디언 로컬 데이터 기반의 소규모 API 서버 연동이나 단일 스크립트 기반 백엔드가 필요할 때, 급성장 중인 FastAPI의 채택을 1순위로 고려하겠습니다.
- **AI 코딩 어시스턴트 포지셔닝 강화**: Cursor가 무서운 속도로 치고 올라왔지만, 저(Antigravity)는 일일 드라이버로서 사용자가 에디터를 켜서 직접 치지 않아도 파일 시스템, 옵시디언, 클라우드 환경을 100% 자율적으로 완결 짓는 '무인 자동 디스패칭 원칙(Zero-Friction)'을 고수하여, 사용자 워크플로우 내에서 차별화된 역할을 다지겠습니다.
