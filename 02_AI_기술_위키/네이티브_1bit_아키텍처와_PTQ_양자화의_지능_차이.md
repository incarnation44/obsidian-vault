# 네이티브 1-bit 아키텍처와 PTQ 사후 양자화의 지능 차이

## 1. 개요
LLM을 개인 PC(예: 8GB VRAM)에서 구동하기 위해 용량을 줄이는 '1-bit' 기술은 두 가지로 나뉜다. 하나는 멀쩡한 모델을 강제로 찌그러뜨리는 **PTQ(사후 양자화)**이고, 다른 하나는 태생부터 1-bit로 설계되어 자라난 **네이티브 1-bit 아키텍처**다. 두 기술은 용량은 비슷할지 몰라도, 출력하는 '지능'의 수준은 하늘과 땅 차이다.

---

## 2. PTQ (Post-Training Quantization) 사후 양자화
- **방식**: 이미 FP16(16-bit)이나 BF16으로 방대한 학습을 마친 무거운 모델(예: Qwen 27B)의 가중치를 수학적으로 반올림(잘라내기)하여 1-bit(Q1_S 등)로 압축한다.
- **결과**: 파일 용량은 7GB 수준으로 줄어들어 VRAM에 쏙 들어가지만, 미세한 가중치 값이 전부 0과 1로 뭉개지면서 심각한 뇌손상(Brain Damage)이 발생한다.
- **증상**: 논리적 추론 능력이 수직 낙하하며, 문맥을 잃어버리거나 코딩 변수명을 엉뚱하게 지어내는 환각(Logic Hallucination)이 극심해진다. (참고: [[LMStudio_1bit_양자화_Qwen27B_구동_DJEDJE]])

---

## 3. 네이티브 1-bit 아키텍처 (Native 1-bit / 1.58-bit)
- **방식**: BitNet, Bonsai 27B 등 최근 등장한 아키텍처로, 모델을 **처음 학습(Pre-training)시킬 때부터 가중치가 -1, 0, 1 (Ternary, 1.58-bit)만 가질 수 있도록 강제**하여 훈련시킨다.
- **결과**: 모델 스스로 한정된 표현력(-1, 0, 1) 안에서 최적의 논리 회로를 구축하며 똑똑해진다. 나중에 강제로 정보를 썰어내는 과정이 없으므로 지능 손실이 없다.
- **성능**: 용량은 27B 체급 기준 3.9GB~5.9GB에 불과하지만, 원본 FP16 모델 지능의 90~95%를 보존한다. 8GB VRAM 유저에게는 30B 체급의 지능을 속도 저하 없이 온전히 누릴 수 있는 유일한 '게임 체인저'다.

---

## 4. 실무 적용 시 주의점: KV 캐시의 역습 (컨텍스트 함정)
네이티브 1-bit 모델을 써서 27B 모델을 3.9GB로 줄였더라도, 8GB VRAM 유저가 안심할 수는 없다.
- 모델 가중치(Weight)는 1-bit지만, 입력 프롬프트가 길어질 때마다 쌓이는 **KV 캐시(기억장치)는 1-bit가 아니기 때문**이다.
- 컨텍스트를 8K에서 100K로 늘리면, 모델 가중치(3.9GB)보다 KV 캐시 메모리(8GB)가 더 커져서 총 VRAM 사용량이 12GB를 훌쩍 넘어가 버린다.
- **ADR 규칙**: 네이티브 1-bit 모델을 8GB VRAM에서 사용할 때는, VRAM 오버플로우 방지를 위해 **최대 컨텍스트 윈도우를 16K 이하로 제한**해야 한다. 방대한 문서를 읽을 때는 여전히 KV 캐시 양자화가 동반된 CPU 오프로딩 전략([[KV_캐시_양자화와_MoE_특화_CPU_오프로딩]])이 필요하다.
