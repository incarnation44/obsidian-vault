# 🛡️ 윈도우 11 시스템 복원 지점 생성 및 1분 긴급 복구 완전정복
> 2026-08-15: `01_PC_및_시스템_최적화` 에서 이 폴더로 옮김. 옛 경로는 스텁.

> **"컴퓨터가 악성코드에 걸리거나 블루스크린/먹통 오류가 났을 때, 수리 기사 부르지 않고 1분 만에 정상 상태로 되돌리는 가장 확실한 백업 보험"**

---

## 📌 핵심 원리 (왜 설정해야 하는가?)

* 윈도우의 레지스트리, 드라이버, 시스템 파일의 **'완전 무결한 스냅샷(사진)'**을 찍어두는 기능입니다.
* 사진, 문서, 개인 파일은 절대 지워지지 않고 **오직 오류가 난 시스템 설정과 프로그램 상태만 깨끗했던 시점으로 롤백**됩니다.

---

## 🛠️ 1단계: 10초 만에 복원 지점 만들기 (사전 보험)

1. **설정 창 열기**: 키보드의 `Win + R` 누른 뒤 **`SystemPropertiesProtection.exe`** 입력 후 엔터  
   *(방금 에이전트가 화면에 창을 띄워 두었습니다!)*
2. **시스템 보호 켜기**:
   * 목록에서 **`로컬 디스크 (C:) (시스템)`** 선택 ➔ **[구성]** 버튼 클릭
   * **`시스템 보호 사용`**에 체크 ➔ 최대 사용량을 **`5% ~ 10% (약 10~20GB)`**로 맞춘 후 [확인]
3. **복원 지점 생성**:
   * 하단의 **[만들기]** 버튼 클릭
   * 이름에 오늘 날짜 입력 (예: `2026-08-14_정상클린상태`) ➔ **[만들기]** 클릭
   * *"복원 지점을 만들었습니다"* 메시지가 뜨면 완료!

---

## 🚨 2단계: 컴퓨터 고장/먹통 시 1분 만에 살려내는 법 (긴급 복구)

컴퓨터가 켜지지 않거나 오류가 날 때 아래 **2가지 방법** 중 하나로 복구합니다.

### 방법 A. 윈도우가 켜질 때 (초간단)
1. `Win + R` 누르고 `rstrui.exe` 입력 후 엔터 (시스템 복원 마법사 실행)
2. 만들어 둔 **`2026-08-14_정상클린상태`** 복원 지점 선택 ➔ [다음] ➔ [마침]
3. PC가 자동으로 재부팅되며 1분 만에 오류 발생 전으로 롤백 완료!

### 방법 B. 윈도우가 심각하게 멈추거나 먹통일 때 (안전모드 진입)
1. 시작 메뉴에서 **`Shift` 키를 꾹 누른 상태로 [다시 시작]** 클릭
2. 파란 화면이 뜨면 **[문제 해결]** ➔ **[고급 옵션]** ➔ **[시스템 복원]** 클릭
3. 저장해 둔 복원 지점을 선택하면 즉시 완벽 복구!
