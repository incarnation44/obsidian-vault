# 📱 옵시디언 모바일 무료 동기화 가이드 (Remotely Save + GitHub)

> **생성일**: 2026-08-07  
> **목적**: Obsidian Sync(유료) 없이 PC와 스마트폰(iOS/Android) 간의 보관소 노트 100% 무료 실시간 동기화 세팅 가이드

---

## ⚡ 1. PC 옵시디언 세팅 (현재 띄워놓은 설정 창 기준)

현재 열어두신 **[설정]** 창에서 순서대로 따라하시면 됩니다.

1. **커뮤니티 플러그인 활성화**
   - 좌측 메뉴에서 **`커뮤니티 플러그인`** 클릭
   - **`커뮤니티 플러그인 켜기` (Turn on community plugins)** 버튼 클릭

2. **Remotely Save 플러그인 설치**
   - **`탐색` (Browse)** 버튼 클릭
   - 검색창에 `Remotely Save` 입력 후 검색
   - `Remotely Save` 선택 ➡️ **`설치` (Install)** ➡️ **`활성화` (Enable)** 클릭

3. **GitHub 계정 연동**
   - 설치된 `Remotely Save` 우측 톱니바퀴(설정) 아이콘 클릭
   - **Method (방식)**: `GitHub` 선택
   - 저장소(Repository): `incarnation44/obsidian-vault` 연결 (Personal Access Token 또는 OAuth 인증)

---

## 📱 2. 스마트폰(모바일) 옵시디언 세팅

1. **Obsidian 앱 설치** (앱스토어 / 구글 플레이스토어에서 무료 다운로드)
2. **새 보관소 생성**: 핸드폰에서 `전일도` 이름으로 새 보관소 만들기
3. **Remotely Save 플러그인 동일 설치**
   - 모바일 Obsidian ⚙️ [설정] ➡️ [커뮤니티 플러그인] 켜기
   - `Remotely Save` 검색 후 설치 & 활성화
4. **PC와 동일한 GitHub 계정 연동**
   - PC에서 설정한 동일한 GitHub 저장소정보 입력
   - **Sync (동기화)** 버튼 클릭시 PC의 모든 노트가 핸드폰으로 즉시 동기화됩니다.

---

## 💡 주요 특징 및 장점

- **100% 무료**: Obsidian Sync 유료 결제($4~$5/월) 불필요
- **버전 관리**: GitHub 커밋 이력이 남으므로 안전한 백업 유지
- **자동 동기화**: 앱 실행 시 및 일정 시간 간격 자동 Sync 가능
