## 💡 3줄 핵심 요약
1. **OS 넘나드는 로지텍 Flow**: 맥북과 윈도우 데스크탑 사이에 마우스 커서를 모니터 끝으로 넘기기만 하면 페어링이 즉시 전환되고, 텍스트와 대용량 파일까지 `Ctrl+C / Ctrl+V`로 복사·이동된다.
2. **MagSpeed 초고속 휠 & 앱별 맞춤 매핑**: 휠을 빠르게 튕기면 50페이지 문서도 1초 만에 넘기는 무한 스크롤로 자동 전환되며, 사용하는 프로그램(크롬, 엑셀, 코딩 툴)마다 버튼 기능이 실시간 자동 분기된다.
3. **AI 프롬프트 빌더 & 스마트 액션 원클릭 자동화**: 마우스 버튼 하나로 ChatGPT를 즉시 호출해 프롬프트를 실행하고, 클릭 한 번으로 작업에 필요한 여러 앱과 웹사이트를 동시에 띄우는 루틴 매크로를 완성한다.

## 🛠️ 기능별 상세 설정 및 사용법

### 1. 로지텍 Flow (이종 OS 간 마우스 전환 & 파일 복사/붙여넣기)
- **핵심 기능**:
  - 맥북(macOS) ↔ 윈도우 데스크탑/노트북(Windows) 간 경계 없는 마우스 이동.
  - 별도 USB 메모리나 클라우드 없이 파일/텍스트를 한쪽 기기에서 복사(`Ctrl+C` 또는 `Cmd+C`) 후 반대쪽 기기 화면으로 넘어가 붙여넣기(`Ctrl+V`).
- **상세 설정법**:
  1. 두 기기를 **동일한 로컬 네트워크(동일 Wi-Fi 공유기 또는 유선 LAN)**에 연결한다.
  2. 양쪽 기기에 **Logi Options+** 프로그램을 설치하고 마우스/키보드를 각각 블루투스 또는 볼트 수신기로 페어링한다.
  3. Logi Options+ 앱 좌측 메뉴에서 **[Flow]** 탭 선택 ➔ **[Flow 사용 설정]** 활성화.
  4. 화면에 감지된 두 기기의 모니터 배치(좌/우 위치)를 실제 책상 배치와 동일하게 드래그하여 정렬한다.
  5. **[복사하여 붙여넣기(클립보드 공유)]** 옵션을 반드시 켜준다.

---

### 2. MagSpeed 스마트 초고속 스크롤 (SmartShift)
- **핵심 기능**:
  - 휠을 천천히 돌리면 정확한 줄 단위 이동(래칫 모드), 빠르게 휙 튕기면 1초에 1,000줄을 내리는 초고속 무한 휠 모드로 자동 변환.
- **상세 설정법**:
  1. Logi Options+ ➔ 마우스 선택 ➔ **[포인트 및 스크롤]** 탭 진입.
  2. **[SmartShift]** 토글을 활성화한다.
  3. 본인 손맛에 맞게 **SmartShift 감도(휠 튕김 감지 임계값)**를 조절한다. (민감하게 설정할수록 살짝만 튕겨도 초고속 모드로 전환됨)

---

### 3. 앱별 버튼 프로필 커스터마이징 (App-Specific Profiles)
- **핵심 기능**:
  - 크롬에서는 '탭 닫기/새 탭 열기', 엑셀에서는 '가로 스크롤/시트 전환', 개발 툴에서는 '터미널 열기/빌드 실행' 등으로 활성 창에 따라 버튼 기능이 실시간 자동 변경됨.
- **상세 설정법**:
  1. Logi Options+ 우측 상단 **[+ 앱 추가]** 버튼 클릭.
  2. 자주 쓰는 앱(Chrome, VS Code, Excel 등)을 목록에 추가.
  3. 해당 앱을 선택한 상태에서 마우스의 제스처 버튼, 앞/뒤로 가기 버튼, 휠 클릭 버튼에 원하는 단축키/기능을 지정.

---

### 4. Logi AI 프롬프트 빌더 (ChatGPT 원클릭 연동)
- **핵심 기능**:
  - 마우스/키보드 버튼 클릭 한 번으로 ChatGPT 팝업 창을 띄우고, 자주 쓰는 프롬프트 템플릿(요약, 문체 수정, 번역 등)을 즉시 적용.
- **상세 설정법**:
  1. Logi Options+ ➔ **[AI 프롬프트 빌더]** 설정 메뉴 진입.
  2. 마우스의 특정 버튼(엄지 제스처 버튼 또는 모드 전환 버튼)에 **[AI Prompt Builder 실행]**을 할당.
  3. 텍스트를 드래그한 뒤 해당 버튼을 누르면 AI 창이 즉시 열리며 원클릭으로 가공/요약 수행.

---

### 5. 스마트 액션 (Smart Actions) 작업 루틴 자동화
- **핵심 기능**:
  - 출근 직후 또는 작업 시작 시 마우스 클릭 한 번으로 '지정 웹사이트 3개 열기 + 슬랙/노션 실행 + 화면 분할 정렬'을 매크로처럼 1초 만에 자동 실행.
- **상세 설정법**:
  1. Logi Options+ ➔ **[Smart Actions]** 탭 클릭 ➔ **[새 스마트 액션 만들기]**.
  2. **트리거**: 원하는 마우스/키보드 버튼 지정.
  3. **동작 추가**:
     - [앱 열기] ➔ 자주 쓰는 프로그램 선택
     - [URL 열기] ➔ 자주 방문하는 대시보드/사이트 링크 등록
     - [키보드 단축키] ➔ 화면 분할 단축키(`Win + 좌/우 화살표`) 등 연속 등록
  4. 저장 후 버튼을 누르면 모든 작업 준비가 단 1초 만에 완료됨.

---

### 6. Logi Bolt (로지 볼트) USB-C 수신기
- **핵심 특징**:
  - 기존 유니파잉 대비 지연 시간 최대 8배 감소 (밀집 무선 환경에서도 끊김 없는 연결).
  - 엔터프라이즈급 보안 표준(FIPS) 적용.
  - USB-C 단자 타입으로 최신 노트북/PC에 젠더 없이 직결 가능.
  - 단일 볼트 수신기 1개에 최대 6대의 로지텍 호환 기기 동시 연결.
