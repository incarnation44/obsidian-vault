# 💻 와.. 컴퓨터에 이런 기능이 숨어있었다고? (윈도우11 5대 필수 꿀팁)
> 2026-08-15: `01_PC_및_시스템_최적화` 에서 이 폴더로 옮김. 옛 경로는 스텁.

---

## 📌 3줄 핵심 요약

1. **작업 표시줄 1초 강제 종료**: 설정에서 '작업 끝내기'를 켜두면 프로그램이 멈췄을 때 작업표시줄 아이콘 우클릭만으로 즉시 강제 종료할 수 있다.
2. **시계 옆 요일 표시 & 전체 프로그램 1초 업데이트**: 국가 설정에서 `ddd`를 추가해 요일을 띄우고 `winget upgrade --all`로 모든 프로그램을 일괄 업데이트한다.
3. **수리비 10만 원 아끼는 시스템 복원 지점**: '복원 지점 만들기'를 미리 켜두면 PC 오류 발생 시 Shift 누른 채 재부팅하여 정상 상태로 원클릭 롤백할 수 있다.

---

## 🛠️ 윈도우11 숨겨진 5대 꿀팁 상세 가이드

### 1. 작업 표시줄에서 바로 프로그램 강제 종료
* **설정 경로**: `설정` ➔ `시스템` ➔ `개발자용` ➔ **`작업 끝내기(End Task)` 활성화**
* **효과**: 게임이나 프로그램이 멈췄을 때 `Ctrl + Alt + Del` 누를 필요 없이 작업 표시줄 아이콘 우클릭 ➔ **[작업 끝내기]** 클릭으로 1초 만에 킬.

---

### 2. 작업 표시줄 시계 옆에 '요일' 항상 표시하기
* **설정 경로**: `검색창` ➔ `국가 또는 지역` ➔ `추가 설정` ➔ `날짜` 탭
* **설정값**: 간단한 날짜 뒤에 **` ddd`** 추가 (예: `yyyy-MM-dd ddd` 또는 `yy-MM-dd'('ddd')'`)
* **효과**: 시계를 누르지 않아도 작업표시줄에 `26-08-14 (금)` 형태로 깔끔하게 표시됨.

---

### 3. PC 내 모든 프로그램 한 번에 일괄 업데이트
* **실행법**: `CMD(명령 프롬프트)`를 관리자 권한으로 실행 ➔ 아래 명령어 입력 후 엔터
  ```powershell
  winget upgrade --all
  ```
* **효과**: 카카오톡, 크롬, 디스코드 등 PC에 설치된 모든 소프트웨어를 1초 만에 최신 보안 패치 버전으로 일괄 업데이트.

---

### 4. 윈도우 정품 인증 알림 타이머 리셋
* **실행법**: `CMD(명령 프롬프트)` 관리자 권한 실행 ➔ 아래 명령어 입력 후 재부팅
  ```powershell
  slmgr /rearm
  ```
* **효과**: 마이크로소프트 공식 라이선스 인증 타이머를 초기화하여 정품 인증 팝업을 일시 제거.

---

### 5. 수리비 사기 막는 1분 시스템 복원 지점 설정
* **설정법**:
  1. 검색창에 `복원 지점 만들기` 검색
  2. `구성` ➔ `시스템 보호 사용` 체크 ➔ `만들기` 클릭 후 오늘 날짜 입력
* **고장 시 복구법**:
  * `Shift` 키를 누른 상태로 윈도우 `다시 시작` 클릭 ➔ `문제 해결` ➔ `고급 옵션` ➔ `시스템 복원` 선택 시 문제가 생기기 전 정상 상태로 완벽 롤백!
