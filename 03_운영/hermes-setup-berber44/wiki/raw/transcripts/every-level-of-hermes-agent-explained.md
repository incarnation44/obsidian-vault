# Video: Every Level of Hermes Agent Explained

Hermes Agent를 다루는 사용자 성숙도의 7가지 수준(Level 0 ~ 7) 정의 및 실수 패턴 요약.

## Hermes Agent 7단계 레이어
- **Level 0 (Unaware)**: 에이전트를 단순 챗봇처럼 취급하며 일회성 명령만 수행하는 단계.
- **Level 1 (Beginner - Download & Go)**: 에이전트를 로컬 PC에 설치하고 단발성 원샷(One-shot) 프롬프트 및 간단한 도구 호출을 시작하는 단계 (일 30분 절약).
- **Level 2 (Apprentice - Context Engineering)**: 에이전트의 내부 메모리를 본격적으로 활용하고 `soul.md`(또는 유저 페르소나 정의 문서)를 통해 비정형 지식을 자산화하는 단계 (주 5시간 절약).
- **Level 3 (Commands & Skills)**: `/steer`, `/background` 등 슬래시 제어 명령어를 적극 구동하고 적합한 모델을 적재적소에 스위칭하는 단계.
- **Level 4 (The Integrator)**: 외부 도구(Granola, Obsidian 등) 및 다양한 MCP 서버를 연결하여 가용 도구를 확장하는 단계 (단, 과도한 MCP 설치는 지양해야 함).
- **Level 5 (Orchestration)**: 병렬 서브에이전트(Parallel Sub-agents)들을 하위에서 운용하며 다수의 과업을 동시에 분산 처리하는 단계.
- **Level 6 (The Builder - Async Tasks)**: 크론(Cron) 작업 스케줄링을 활성화하여 사용자가 자는 동안에도 에이전트가 백그라운드에서 동기/비동기로 업무를 완료하도록 만드는 단계.
- **Level 7 (Agentic Power User - OS Integration)**: Claude Code, Codex, Antigravity 등의 메모리를 통합하고, 위키 및 대시보드와 유기적으로 결합하여 단일 인공지능 운영체제(AI OS)처럼 운용하는 궁극의 단계.
