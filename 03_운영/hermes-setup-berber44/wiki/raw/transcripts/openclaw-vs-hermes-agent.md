# Video: OpenClaw vs Hermes Agent (Don't choose WRONG!)

Metics Media의 Matt가 두 오픈소스 AI 에이전트(OpenClaw, Hermes Agent)를 실전 설치/운영 경험 기준으로 비교 분석. "둘 다 써라" 식 회피 없이 3가지 사용자 프로필별 명확한 추천 제시.

## 핵심 차이: 설계 철학
| OpenClaw | Hermes Agent |
|----------|--------------|
| **카탈로그 중심** — ClawHub 50,000+ 스킬/플러그인 마켓플레이스. 남이 만든 것 원클릭 설치. | **학습 루프 중심** — Curator가 에이전트 작업을 자동으로 스킬화·축적·리팩토링. 승인 불필요. |
| 커뮤니티 생태계에 베팅 | 에이전트 자기 개선에 베팅 |

---

## OpenClaw가 이기는 3가지

### 1. 압도적 카탈로그 (ClawHub)
- 50,000+ 스킬/플러그인 (Google Workspace, 웹 스크래핑, 이미지 생성, 회계 등)
- 대시보드에서 원클릭 설치. Day 1부터 두꺼운 툴박스.
- **단점**: 보안 이슈(아래 참조).

### 2. 네이티브 프로바이더 다양성
- 50+ AI 프로바이더 기본 지원 (Anthropic, OpenAI, Gemini, Grok, DeepSeek, Ollama 등).
- Hermes는 기본 리스트 짧고(OpenRouter, Anthropic, OpenAI, Nous, Ollama), 나머지는 OpenRouter 경유.

### 3. 기본 탑재 웹 대시보드
- 설치 즉시 쓸 수 있는 폴리시드된 웹 UI.
- Hermes는 CLI 우선, 대시보드는 별도 설치 필요.

---

## Hermes가 이기는 3가지

### 1. 자동 학습 루프 (Curator) — **핵심 차별점**
- 에이전트가 문제를 풀 때마다 스킬 자동 생성·축적·리팩토링·사용률 모니터링.
- OpenClaw는 2026년 6월 'Skill Workshop'으로 유사 기능 추가했으나 **기본 OFF**, 스킬 제안마다 사용자 승인 필요. Hermes는 완전 자동.

### 2. 반복 작업 토큰 비용 절감
- 같은 작업 반복 시 Hermes: 한 번 풀고 스킬로 저장 → 이후 거의 공짜로 실행.
- OpenClaw: Skill Workshop으로 가능하나 매 스킬 승인 대기 → 절감 실현 느림.
- 다양한 일회성 작업이면 둘 다 비슷.

### 3. Day-1 사용성 (기본값이 타이트)
- 프로바이더 고르고 키 붙여넣고 바로 채팅 시작. 마찰 최소.
- OpenClaw는 설정 지점이 많아 Day-1에 막힐 포인트 다수.

---

## 설치 난이도 & 비용
- **둘 다 원클릭 VPS 템플릿 제공** (Hostinger 등). KVM 2급 이상 권장. 터미널/Docker/서버 설정 불필요.
- **서버 비용**: 동일 (물리/가상 머신).
- **모델 비용**: 동일 (같은 모델 사용, 프롬프트 캐싱 ~90% 동일).
- **실질 차이**: 반복 작업 시 Hermes가 더 일찍 비용 평탄화.
- **월 $20 이하**로 편안히 운영 가능(가장 싼 모델 기준).

## 보안 & CVE 이력 — **중요**

| 항목 | OpenClaw | Hermes |
|------|----------|--------|
| **2026년 상반기 CVE** | 130+ 건 (2~4월 집중) | 최소 12건 (2026년 전체) |
| **치명적 이슈** | 고위험 RCE (악성 링크로 게이트웨이 탈취). 40,000+ 인스턴스 노출. 패치 완료. | 4월 감사에서 Critical 4건, High 9건 발견. 후속 버전에서 패치. |
| **서드파티 스킬 감사** | ClawHub 1,000+ 악성 스킬 플래그. | 서드파티 마켓플레이스 없음 → 공격 표면 작음. |
| **권장 대응** | 신뢰할 수 있는 퍼블리셔 스킬만 설치, 버전 최신 유지. | 동일하게 최신 유지. |

**결론**: 둘 다 업데이트만 잘하면 안전. OpenClaw가 생태계 크기만큼 공격 표면도 큼.

## 추천 프레임워크 (3 프로필)

| 프로필 | 추천 | 이유 |
|--------|------|------|
| **초보/개인 비서용** (Telegram/Discord 개인 비서, 설정 튜닝 싫음, 오래 쓸수록 나아지길 원함) | **Hermes** | Curator 자동 복리, 기본값 타이트, 마찰 최소. |
| **대시보드/마켓플레이스/세밀 제어 원함** (기성 스킬 5만 개 원클릭, 다양한 프로바이더 네이티브, UI 브라우징 선호) | **OpenClaw** | 카탈로그·대시보드·프로바이더 최강. 단, 버전 업데이트·신뢰 퍼블리셔만 설치 필수. |
| **매일 같은 반복 작업** (일일 브리핑, 동일 리서치, 이메일 트리아지 반복 → 비용 절감 원함) | **Hermes** | Curator가 반복 작업 자동 스킬화·저비용화. OpenClaw는 승인 대기 느림. |

## 요약 인사이트 (Minto Pyramid)
**"첫 AI 에이전트이자 장기 비서라면 Hermes(Curator 자동 학습), 기성 스킬 마켓플레이스와 대시보드·프로바이더 다양성이 최우선이면 OpenClaw. 보안은 둘 다 최신 유지 필수이나 OpenClaw가 공격 표면 더 큼."**

## 파인만 비유 (ELI5)
> **OpenClaw** = 거대한 **이케아 매장**. 원하는 가구(스킬) 다 있고 바로 카트에 담아 집(에이전트)에 놓기만 하면 됨. 하지만 조립 설명서(보안) 안 읽고 이상한 거 사면 집 무너질 수 있음.
> 
> **Hermes** = **나만의 목수**. 처음엔 도구 몇 개 없지만, 내가 시키는 일 할 때마다 "아, 이거 이렇게 하면 되네?" 하며 도구(스킬)를 직접 만들고 다듬음. 오래 쓸수록 내 손에 딱 맞는 연장이 늘어남.
