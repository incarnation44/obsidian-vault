## 1. 파이썬 기초 핵심 용어 정리

- **변수 (Variable)**: 데이터를 담는 상자 (예: `name = "전일도"`).
- **함수 (Function)**: 반복되는 명령어를 묶어둔 상자 (예: `def greet(): print("Hello")`).
- **리스트/딕셔너리 (List/Dict)**: 여러 개 데이터를 순서대로 또는 Key-Value 쌍으로 모아둔 구조.
- **모듈/라이브러리 (Module/Library)**: 다른 사람이 만들어 둔 유용한 기능 도구 모음 (`urllib`, `json`, `os`, `time` 등).
- **API (Application Programming Interface)**: 다른 프로그램이나 서버에 데이터를 요청하고 응답받는 창구.

## 2. ⚡ 로컬 AI 파이썬 연동 모듈 (`test_local_ai.py`)

로컬 AI(`http://localhost:11434`)에 파이썬으로 직접 요청을 보내 응답 및 생성 속도(tokens/sec)를 구하는 표준 구현입니다.

```python
import sys
import io
import urllib.request
import json
import time

# Windows 터미널 한글 깨짐 방지
sys.stdout = io.TextIOWrapper(sys.stdout.buffer, encoding='utf-8')

def test_ollama(model_name="qwen2.5:7b", prompt="안녕하세요!"):
    url = "http://localhost:11434/api/generate"
    payload = {"model": model_name, "prompt": prompt, "stream": False}
    headers = {'Content-Type': 'application/json'}
    
    start_time = time.time()
    req = urllib.request.Request(url, data=json.dumps(payload).encode('utf-8'), headers=headers)
    
    with urllib.request.urlopen(req) as response:
        res_json = json.loads(response.read().decode('utf-8'))
        elapsed = time.time() - start_time
        response_text = res_json.get("response", "")
        eval_count = res_json.get("eval_count", 0)
        eval_duration = res_json.get("eval_duration", 1) / 1e9
        tps = eval_count / eval_duration if eval_duration > 0 else 0
        
        print(f"응답: {response_text}")
        print(f"속도: {tps:.2f} tokens/sec (소요시간: {elapsed:.2f}초)")

if __name__ == "__main__":
    test_ollama()
```
