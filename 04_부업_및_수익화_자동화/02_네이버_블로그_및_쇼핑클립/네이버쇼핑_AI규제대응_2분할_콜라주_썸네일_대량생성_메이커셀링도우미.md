## 💡 핵심 요약 (3 Lines)
1. **네이버 쇼핑 정책 변화**: 2026년 7월 10일부터 AI 생성물에 대한 심사 기준이 강화되어 AI 과대 가공 썸네일에 대한 노출 페널티가 본격화됨.
2. **합법적 2분할 콜라주 썸네일의 부활**: 단일 컷 대비 클릭률(CTR)을 높이면서 네이버 기준을 통과하는 가장 안전한 형태는 **'대표 컷 + 20% 이내 서브 컷'** 2분할 콜라주 구조임.
3. **무료 셀러 도구 '메이커 셀링 도우미'**: 대표 이미지 대량 다운로드 기능에 이어, 상품 코드와 이미지 URL 입력만으로 2분할 규격 썸네일을 1초 만에 대량 합성하는 기능을 무료 공개함.

## 🚨 1. 네이버 쇼핑 AI 생성물 규제 강화와 썸네일 트렌드

### ① 2026년 7월 10일 네이버 쇼핑 AI 가이드라인 핵심
* **배경**: AI로 화려하게 가공된 가짜/왜곡 썸네일이 범람하면서 소비자 신뢰도 하락과 반품률 증가 발생.
* **플랫폼 기조**: 알리익스프레스 등 해외 직구 플랫폼과 달리, 네이버와 쿠팡은 **'실물에 기반한 깔끔하고 정돈된 썸네일'**을 선호하며 AI 생성 이미지에 페널티 부여 시작.
* **대응 전략**: 완전히 새로운 AI 이미지를 만들기보다, **실제 공급처의 대표 실물 사진 위에 디테일/착용 컷을 20% 이하 면적으로 깔끔하게 얹는 2분할 콜라주 기법**이 최적의 대안으로 부상.

### ② 왜 '20% 이내 2분할'인가?
* 네이버 쇼핑 가이드라인상 4분할 등 과도한 분할 이미지는 시인성 저하로 제재 대상이 될 수 있음.
* **보조 이미지 크기 비율이 전체 면적의 20%를 넘지 않아야** 네이버 검색 로봇의 검수를 무사 통과하고 클릭률 상승 효과를 동시에 누릴 수 있음.

```
+------------------------------------------+
|                                          |
|                                          |
|            메인 대표 이미지              |
|              (전체 80%+)                 |
|                                          |
|                    +-------------------+ |
|                    |   서브 디테일 컷  | |
|                    |    (20% 이내)     | |
|                    +-------------------+ |
+------------------------------------------+
```

## 🛠️ 2. 메이커 셀링 도우미 주요 기능 및 활용법

### ① 배포 형태
* **데스크톱 앱 (윈도우 전용)**: MS Store 정식 등록 배포 (`메이커 셀링 도우미`)
* **크롬 확장프로그램 (윈도우/맥 공용)**: 웹 브라우저에서 즉시 실행

### ② 신규 업데이트: 대표 이미지 대량 합성 기능
* **입력 데이터**: 상품 코드, 메인 이미지 URL, 보조 이미지 URL
* **샘플 채우기 및 실시간 미리보기**: 보조 이미지의 크기 슬라이더 조절 시 20% 초과 경고 표시.
* **모양 및 위치 커스텀**: 원형/라운드 사각, 우측 하단/좌측 하단 등 자유 배치 후 일괄 [합성 시작] 클릭 시 로컬 폴더로 초고속 자동 렌더링.

### ③ 향후 개발 및 개선 로드맵
1. **로컬 파일 직접 불러오기**: 기존 '대량 다운로더'와 연동하여 다운받은 폴더 내 이미지를 자동으로 읽어와 바로 합성하는 파이프라인.
2. **테두리/쉐이프 옵션 다변화**: 보조 이미지에 화이트 테두리, 그림자(Drop Shadow), 다각형 마스크 지원.
3. **숏폼(Shorts) 숏클립 자동 생성기 부활**: 대표 컷 3장을 조합해 5초~10초 길이의 슬라이드 영상 클립 자동 제작.

## ⚡ 3. AI(Antigravity) 시스템 및 내 워크플로우 적용점 (Actionable Insights)

### 1) 파이썬(Pillow) 기반 100% 로컬 무제한 대량 2분할 합성 스크립트 구축
* 외산 툴이나 프로그램 설치 없이도, 사용자 로컬 PC에서 **폴더 내 수백 개 상품 이미지를 1초 만에 20% 규격 준수 콜라주로 자동 합성**하는 파이썬 스크립트(`create_naver_collage.py`)를 Antigravity가 즉시 생성 및 실행 가능.
* 로컬 처리이므로 이미지 URL 추출 과정 없이 다운받은 폴더 파일명만으로 즉시 일괄 렌더링.

### 2) 네이버 20% 규격 자동 검증기
* 합성 시 보조 이미지의 면적 비율(`width * height / total_area <= 0.20`)을 코드로 강제 고정하여 사람이 일일이 눈대중하지 않아도 100% 네이버 검수 통과 보장.

### 3) 숏폼 영상 제작 자동화 (MoviePy / FFmpeg)
* 추출된 썸네일 3장 + 상품명 텍스트로 네이버 쇼핑 클립 / 틱톡 / 릴스용 9:16 세로형 7초 숏클립 자동 렌더링 파이프라인 연계.
