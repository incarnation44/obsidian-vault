## 📌 1. 컴퓨터 구조 & 운영체제 & 네트워크 (1~7번)

### Q1. 변수(Variable)와 상수(Constant)에 대한 설명으로 옳은 것은?
* **정답**: **① 변수는 실행 중 값을 바꿀 수 있고, 상수는 한 번 정하면 바꿀 수 없다.**
* **선택지**:
  1. 변수는 실행 중 값을 바꿀 수 있고, 상수는 한 번 정하면 바꿀 수 없다. (O)
  2. 변수는 값을 바꿀 수 없고, 상수는 자유롭게 바꿀 수 있다.
  3. 변수와 상수 모두 실행 중에는 값을 바꿀 수 없다.
  4. 변수와 상수는 저장 공간 크기만 다를 뿐 성질은 같다.
* **핵심 해설**: 변수(Variable)는 프로그램 실행 중 값이 변할 수 있는 메모리 공간이며, 상수(Constant)는 초기화 후 변경이 불가능한 고정된 값입니다.

### Q2. 배열(Array)과 연결리스트(Linked List)에 대한 설명으로 옳은 것은?
* **정답**: **① 배열은 인덱스로 접근이 빠르고, 연결리스트는 삽입·삭제가 쉽다.**
* **선택지**:
  1. 배열은 인덱스로 접근이 빠르고, 연결리스트는 삽입·삭제가 쉽다. (O)
  2. 배열은 삽입·삭제가 쉽고, 연결리스트는 인덱스 접근이 빠르다.
  3. 배열은 크기를 자유롭게 늘릴 수 있고, 연결리스트는 크기가 고정이다.
  4. 둘 다 데이터를 포인터로만 연결해 저장한다.
* **핵심 해설**: 배열은 연속된 메모리 공간에 저장되어 O(1)의 빠른 인덱스 임의 접근이 가능합니다. 연결리스트는 노드 포인터 조작만으로 O(1)의 빠른 삽입/삭제가 가능합니다.

### Q3. CPU와 GPU에 대한 설명으로 옳은 것은?
* **정답**: **① CPU는 복잡한 연산을 순차 처리하고, GPU는 단순 연산을 대량 병렬 처리한다.**
* **선택지**:
  1. CPU는 복잡한 연산을 순차 처리하고, GPU는 단순 연산을 대량 병렬 처리한다. (O)
  2. CPU는 코어가 매우 많고, GPU는 코어가 적다.
  3. GPU는 복잡한 제어에 강하고, CPU는 그래픽 전용이다.
  4. AI 학습에는 병렬 처리가 약한 CPU가 GPU보다 유리하다.
* **핵심 해설**: CPU는 소수의 고성능 코어로 복잡한 직렬/순차 연산 및 제어에 특화되어 있고, GPU는 수천 개의 경량 코어로 대규모 행렬 연산 등의 단순 병렬 처리에 특화되어 AI 학습에 필수적입니다.

### Q4. 메모리(RAM)와 디스크(스토리지)에 대한 설명으로 옳은 것은?
* **정답**: **① 메모리는 실행 중 임시 저장용, 디스크는 장기 저장용이다.**
* **선택지**:
  1. 메모리는 실행 중 임시 저장용, 디스크는 장기 저장용이다. (O)
  2. 메모리는 전원이 꺼져도 데이터가 남고, 디스크는 사라진다.
  3. 디스크가 메모리보다 접근 속도가 빠르다.
  4. 메모리와 디스크는 둘 다 휘발성 저장장치다.
* **핵심 해설**: RAM(주기억장치)은 전원이 꺼지면 지워지는 휘발성 임시 작업 공간으로 속도가 매우 빠르고, SSD/HDD(보조기억장치)는 비휘발성 영구/장기 저장소입니다.

### Q5. TCP와 UDP에 대한 설명으로 옳은 것은?
* **정답**: **① TCP는 연결을 맺고 신뢰성을 보장하며, UDP는 연결 없이 빠르게 전송한다.**
* **선택지**:
  1. TCP는 연결을 맺고 신뢰성을 보장하며, UDP는 연결 없이 빠르게 전송한다. (O)
  2. TCP는 연결 없이 빠르고, UDP는 신뢰성이 높다.
  3. TCP와 UDP 모두 데이터 손실을 100% 막아 준다.
  4. UDP는 전송 속도가 느리지만 순서를 항상 보장한다.
* **핵심 해설**: TCP는 3-Way Handshake로 연결을 수립하고 패킷 손실 시 재전송하여 신뢰성을 보장합니다. UDP는 비연결형으로 오버헤드가 적어 실시간 스트리밍/영상 전송에 적합합니다.

---

### Q6. 프로세스(Process)와 스레드(Thread)에 대한 설명으로 옳은 것은?
* **정답**: **① 프로세스는 실행 중인 프로그램 단위, 스레드는 그 내부의 실행 단위다.**
* **선택지**:
  1. 프로세스는 실행 중인 프로그램 단위, 스레드는 그 내부의 실행 단위다. (O)
  2. 스레드 안에서 여러 프로세스가 동시에 실행된다.
  3. 프로세스와 스레드는 완전히 같은 말이다.
  4. 한 프로그램은 반드시 하나의 스레드만 가질 수 있다.
* **핵심 해설**: 프로세스는 운영체제로부터 독립된 메모리 자원을 할당받은 실행 인스턴스이며, 스레드는 프로세스 내에서 자원(Code, Data, Heap)을 공유하며 실행되는 가벼운 실행 흐름입니다.

---

### Q7. 스택(Stack)과 큐(Queue)에 대한 설명으로 옳은 것은?
* **정답**: **① 스택은 후입선출(LIFO), 큐는 선입선출(FIFO) 방식이다.**
* **선택지**:
  1. 스택은 후입선출(LIFO), 큐는 선입선출(FIFO) 방식이다. (O)
  2. 스택은 선입선출, 큐는 후입선출 방식이다.
  3. 스택과 큐 모두 먼저 들어온 데이터가 먼저 나간다.
  4. 큐는 항상 마지막에 들어온 데이터부터 꺼낸다.
* **핵심 해설**: 스택은 나중에 들어간 것이 먼저 나오는 LIFO(Last-In First-Out, 뒤로가기/되돌리기), 큐는 먼저 들어간 것이 먼저 나오는 FIFO(First-In First-Out, 대기열/줄서기) 구조입니다.

## 📌 2. 객체 지향 프로그래밍 (OOP, 8~13번)

### Q8. 객체 지향 프로그래밍(OOP)에 대한 설명으로 옳은 것은?
* **정답**: **① 데이터와 기능을 가진 객체 단위로 프로그램을 구성하는 방식이다.**
* **선택지**:
  1. 데이터와 기능을 가진 객체 단위로 프로그램을 구성하는 방식이다. (O)
  2. 기능(함수)을 순서대로 나열하는 것만을 의미한다.
  3. 데이터를 전혀 사용하지 않고 기능만 다룬다.
  4. 하드웨어를 직접 제어하는 저수준 프로그래밍 방식이다.
* **핵심 해설**: 객체지향은 프로그램의 구성 요소를 데이터(속성)와 메서드(행동)를 하나로 묶은 객체로 모델링하여 유지보수성과 재사용성을 극대화하는 패러다임입니다.

---

### Q9. 클래스(Class)와 객체(Object)의 관계로 옳은 것은?
* **정답**: **① 클래스는 설계도, 객체는 그 설계도로 만든 실제 인스턴스다.**
* **선택지**:
  1. 클래스는 설계도, 객체는 그 설계도로 만든 실제 인스턴스다. (O)
  2. 객체는 설계도, 클래스는 그것으로 만든 결과물이다.
  3. 클래스와 객체는 완전히 같은 것이다.
  4. 하나의 클래스로는 객체를 하나만 만들 수 있다.
* **핵심 해설**: 클래스는 붕어빵 틀(청사진/설계도)이며, 객체(인스턴스)는 그 틀을 통해 메모리에 실제로 실체화된 붕어빵입니다.

---

### Q10. 캡슐화(Encapsulation)에 대한 설명으로 옳은 것은?
* **정답**: **① 데이터와 기능을 묶고 외부의 직접 접근을 제한하는 것이다.**
* **선택지**:
  1. 데이터와 기능을 묶고 외부의 직접 접근을 제한하는 것이다. (O)
  2. 모든 데이터를 외부에서 자유롭게 수정하도록 여는 것이다.
  3. 클래스를 여러 개로 쪼개는 작업을 말한다.
  4. 프로그램 실행 속도를 높이는 압축 기술이다.
* **핵심 해설**: 캡슐화는 연관된 데이터와 함수를 하나로 묶고, 접근 제어자(private 등)를 통해 내부 구현을 감추고(정보 은닉) 외부의 무분별한 직접 접근을 차단합니다.

---

### Q11. 상속(Inheritance)에 대한 설명으로 옳은 것은?
* **정답**: **① 기존 클래스의 속성·메서드를 새 클래스가 물려받아 재사용한다.**
* **선택지**:
  1. 기존 클래스의 속성·메서드를 새 클래스가 물려받아 재사용한다. (O)
  2. 객체가 실행 중 자신의 데이터를 삭제하는 기능이다.
  3. 서로 관련 없는 클래스를 강제로 합치는 것이다.
  4. 코드 중복을 늘려 가독성을 떨어뜨리는 방식이다.
* **핵심 해설**: 부모 클래스의 필드와 메서드를 자식 클래스가 물려받아 코드의 중복을 제거하고 기능의 확장성을 부여합니다.

---

### Q12. 객체 지향 프로그래밍의 4가지 특징에 해당하지 않는 것은?
* **정답**: **④ 컴파일링 (Compiling)**
* **선택지**:
  1. 캡슐화 (Encapsulation)
  2. 상속 (Inheritance)
  3. 다형성 (Polymorphism)
  4. 컴파일링 (Compiling) (O - 오답 선택)
* **핵심 해설**: 객체 지향 프로그래밍의 4대 핵심 특징은 1) 캡슐화, 2) 상속, 3) 다형성, 4) 추상화(Abstraction)입니다. 컴파일링은 소스 코드를 기계어로 번역하는 빌드 단계입니다.

---

### Q13. 생성자(Constructor)에 대한 설명으로 옳은 것은?
* **정답**: **① 객체가 생성될 때 자동으로 호출되어 초기값을 설정한다.**
* **선택지**:
  1. 객체가 생성될 때 자동으로 호출되어 초기값을 설정한다. (O)
  2. 객체가 소멸될 때만 수동으로 호출된다.
  3. 클래스 자체를 삭제하는 역할을 한다.
  4. 객체 외부의 데이터를 강제로 변경한다.
* **핵심 해설**: 파이썬의 __init__ 메서드처럼 객체가 메모리에 인스턴스화되는 순간 가장 먼저 자동 호출되어 초기 속성값을 설정하는 특수 메서드입니다.

## 📌 3. 인공지능 & 머신러닝 & Vision AI (14~20번)

### Q14. 머신러닝과 딥러닝에 대한 설명으로 옳은 것은?
* **정답**: **① 딥러닝은 머신러닝의 한 분야로, 신경망으로 특징까지 스스로 학습한다.**
* **선택지**:
  1. 딥러닝은 머신러닝의 한 분야로, 신경망으로 특징까지 스스로 학습한다. (O)
  2. 머신러닝은 딥러닝의 한 종류로, 항상 신경망만 사용한다.
  3. 딥러닝은 사람이 일일이 특징을 정해 줘야만 작동한다.
  4. 머신러닝과 딥러닝은 데이터 없이 규칙을 만든다.
* **핵심 해설**: 딥러닝(심층신경망)은 머신러닝의 하위 분야로, 사람이 수동으로 추출하던 특징(Feature)을 데이터로부터 모델이 스스로 학습합니다.

### Q15. 일반 SW 개발과 AI 개발의 차이로 옳은 것은?

* **선택지**:
  1. 일반 개발은 사람이 규칙을 직접 코딩하고, AI는 데이터로 규칙을 학습한다. (O)
  2. 일반 개발은 데이터로 규칙을 학습하고, AI는 규칙을 직접 코딩한다.
  3. 둘 다 사람이 규칙을 직접 작성해야 한다.
  4. AI 개발에는 데이터가 전혀 필요 없다.
* **핵심 해설**: 일반 SW는 사람이 명시적 규칙을 코딩하여 답을 구하는 방식이고, AI/ML은 데이터와 정답을 바탕으로 규칙(모델 가중치)을 스스로 학습하는 방식입니다.

### Q18. 합성데이터(Synthetic Data)에 대한 설명으로 옳은 것은?
* **정답**: **① 실제 수집 대신 시뮬레이션·생성 모델로 인공 생성한 데이터다.**
* **선택지**:
  1. 실제 수집 대신 시뮬레이션·생성 모델로 인공 생성한 데이터다. (O)
  2. 실제 현장에서 직접 수집한 원본 데이터만을 말한다.
  3. 데이터를 삭제·폐기하는 절차를 의미한다.
  4. 사람이 손으로 직접 그린 그림만을 가리킨다.
* **핵심 해설**: 3D 그래픽 엔진이나 생성 AI(GAN/Diffusion) 등을 활용해 현실에서 구하기 어렵거나 위험한 산업 현장 데이터를 인공적으로 가상 생성한 데이터입니다.

### Q19. 학습데이터를 training data와 test data로 나누는 이유로 옳은 것은?
* **정답**: **① 학습에 쓰지 않은 데이터로 새 데이터에서의 성능을 평가하기 위해**
* **선택지**:
  1. 학습에 쓰지 않은 데이터로 새 데이터에서의 성능을 평가하기 위해 (O)
  2. 데이터 용량을 절반으로 줄이기 위해
  3. 두 데이터를 똑같이 학습에만 사용하기 위해
  4. 정답(라벨)을 모두 없애기 위해
* **핵심 해설**: 모델이 훈련 데이터에만 과도하게 맞춰지는 과적합(Overfitting)을 방지하고, 새로운 실제 환경 데이터에 대한 일반화(Generalization) 성능을 검증하기 위해 분리합니다.

### Q20. Vision AI에서 주로 사용하는 기술로 보기 어려운 것은?
* **정답**: **④ 음성 합성 (Speech Synthesis)**
* **선택지**:
  1. 객체 검출 (Object Detection)
  2. 자세 추정 (Pose Estimation)
  3. 이미지 분류 (Image Classification)
  4. 음성 합성 (Speech Synthesis) (O - 오디오 분야 기술)
* **핵심 해설**: Vision AI는 시각(이미지/영상)을 다루는 인공지능 기술(분류, 검출, 세그멘테이션, 포즈 추정 등)이며, 음성 합성은 오디오/자연어 처리 분야의 기술입니다.
