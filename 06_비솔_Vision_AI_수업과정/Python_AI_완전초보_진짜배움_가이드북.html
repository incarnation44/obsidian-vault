1단계. 인공지능은 기존 프로그램과 무엇이 다를까?

💡 [질문] 계산기와 인공지능의 결정적 차이는 무엇일까요?

우리가 흔히 쓰는 계산기나 엑셀은 사람이 작성해 준 규칙(규칙 기반)대로만 움직입니다. 예를 들어 "만약 비가 오면 우산을 챙겨라"라는 규칙을 사람이 1,000줄 작성해 주어야 합니다. 만약 사람이 적어주지 않은 상황이 발생하면 컴퓨터는 멈추거나 엉뚱한 오작동을 일으킵니다.

반면 인공지능(기계학습)은 규칙을 사람이 적지 않습니다. 대신 컴퓨터에게 과거 10년 치 날씨와 수만 장의 사람 사진(데이터)을 보여줍니다. 그러면 컴퓨터가 스스로 "아, 하늘이 어두워지고 먹구름이 끼면 사람들이 우산을 쓰는구나!"라는 패턴과 규칙을 스스로 찾아냅니다.

1. 튜링 테스트 (Turing Test)

1950년 수학자 앨런 튜링이 제안한 인공지능 판별법입니다. 보이지 않는 방 너머로 컴퓨터와 사람이 채팅으로 대화할 때, 심사위원이 "지금 대화하는 상대가 사람인지 기계인지 구별할 수 없다면" 그 기계는 지능이 있다고 정의합니다.

2. 약인공지능 vs 강인공지능

  • 약인공지능 (Narrow AI): 한 가지 정해진 일만 사람보다 잘하는 AI입니다. 바둑을 두는 알파고, 얼굴을 인식하는 스마트폰 카메라, 번역기 등이 여기에 해당합니다. (현재 인류가 개발한 모든 AI는 약인공지능입니다.)
  • 강인공지능 (AGI): 사람처럼 스스로 생각하고, 자의식을 가지며, 새로운 분야를 만능으로 스스로 학습하는 AI입니다. (아직 세상에 나오지 않았습니다.)
🚨 시험에 꼭 나오는 핵심: 기호주의 vs 연결주의 & 모라벡의 역설
1. 기호주의: 사람이 규칙과 지식을 직접 손으로 코딩하는 방식 (초기 전문가 시스템).
2. 연결주의: 인간 뇌세포(뉴런)의 연결 구조를 흉내 내어 데이터로부터 스스로 학습하는 방식 (현대 딥러닝).
3. 모라벡의 역설: 사람에게 쉬운 시각 인식이나 걷기는 컴퓨터에게 엄청나게 어렵고, 사람에게 어려운 체스나 복잡한 수학 계산은 컴퓨터에게 너무나 쉬운 기현상.

2단계. 컴퓨터는 사진과 글자를 어떻게 이해할까? (파이썬과 셈 지능)

💡 [핵심] 컴퓨터의 세계에서 모든 것은 '숫자'입니다
컴퓨터는 눈과 귀가 없습니다. 모니터에 보이는 고양이 사진도 컴퓨터에게는 가로 28칸, 세로 28칸의 숫자 격자판(0=검정, 255=흰색)으로 보입니다. 음성도 소리의 높낮이를 나타내는 숫자이고, 단어도 고유한 번호(숫자)입니다.
따라서 인공지능을 공부한다는 것은 수많은 숫자로 이루어진 행렬(표)을 빠르게 계산하는 법을 배우는 것입니다.

1. 왜 파이썬에서 NumPy(넘파이)를 필수로 쓸까?

파이썬의 일반 for 반복문은 속도가 매우 느립니다. 수백만 장의 픽셀 숫자를 하나씩 더하다 보면 며칠이 걸립니다. 하지만 NumPy는 C언어로 만들어져 있어, 수백만 개의 숫자를 컴퓨터의 CPU/GPU 명령어로 동시에 한 번에(벡터화 연산) 처리합니다. 

import numpy as np

# 2x2 숫자 표(행렬) 2개 만들기
A = np.array([[1, 2], [3, 4]])
B = np.array([[5, 6], [7, 8]])

# [시험 단골 구분!]
# 1. 요소별 곱 (*): 같은 자리에 있는 숫자끼리 단순히 곱하기
print(A * B)        # [[ 1*5, 2*6 ], [ 3*7, 4*8 ]] -> [[ 5, 12], [21, 32]]

# 2. 행렬 곱 (@ 또는 np.dot): 가로줄과 세로줄을 곱해서 더하기 (신경망 연산의 기본!)
print(A @ B)        # [[ 1*5 + 2*7, 1*6 + 2*8 ], [ 3*5 + 4*7, 3*6 + 4*8 ]]
                    # -> [[ 19, 22 ], [ 43, 50 ]]

3단계. 기계학습(머신러닝)은 어떻게 공부하고 채점할까?

1. 3가지 공부 방법

  • 지도학습 (Supervised Learning): 문제($X$)와 정답($Y$)을 함께 주며 가르칩니다.
    • 회귀 (Regression): 내일의 기온이나 집값처럼 연속된 숫자를 맞히는 문제.
    • 분류 (Classification): 스팸 메일인지 정상 메일인지 선택지 중 하나를 맞히는 문제.
  • 비지도학습 (Unsupervised Learning): 정답 없이 문제($X$)만 던져주고, "비슷한 성향의 고객들끼리 무리를 지어봐"라고 스스로 묶게 만드는 방식 (군집화).
  • 강화학습 (Reinforcement Learning): 게임처럼 잘하면 상(보상)을 주고, 실수하면 벌점을 주어 최선의 전략을 스스로 터득하게 하는 방식 (알파고).

2. 과적합(Overfitting)이란 무엇일까?

학생이 교과서 문제의 원리를 이해하지 않고 연습 문제와 답의 번호만 통째로 외운 상태를 말합니다. 이 학생은 교과서 시험(훈련 데이터)은 100점을 맞지만, 숫자가 조금만 바뀐 실전 수능(테스트 데이터)에서는 0점을 맞게 됩니다. 이를 과적합이라고 하며, 인공지능 개발자가 가장 경계해야 할 현상입니다.

3. 성능 평가의 핵심: 왜 정확도(Accuracy) 하나만으로 안 될까?

🚨 [시험 1순위] 정밀도(Precision)와 재현율(Recall)의 차이
만약 인구의 99%가 정상이고 1%만 희귀 암 환자라면, 아무것도 모르는 바보 AI가 모든 사람에게 "정상입니다!"라고만 대답해도 정확도는 99%가 나옵니다. 하지만 암 환자를 단 한 명도 못 잡았으므로 쓸모없는 AI입니다.

• 재현율 (Recall): "실제 암 환자 100명 중 AI가 놓치지 않고 찾아낸 비율."
👉 암 진단처럼 정답을 놓치면 치명적인 곳에서는 재현율이 가장 중요합니다.

• 정밀도 (Precision): "AI가 '스팸 메일'이라고 판정한 것 중 진짜 스팸인 비율."
👉 스팸 메일함처럼 정상적인 중요 업무 메일을 스팸으로 지워버리면 안 되는 곳에서는 정밀도가 가장 중요합니다.

4단계. 인공 신경망의 뇌세포(퍼셉트론)는 어떻게 생각할까?

1. 퍼셉트론 (Perceptron)의 의사결정 원리

우리가 "오늘 친구를 만나러 나갈까?"를 고민할 때 머릿속에서 여러 조건을 저울질합니다:

  1. 날씨가 좋은가? ($x_1$) ➡️ 아주 중요함! 중요도(가중치 $w_1 = 10$)
  2. 숙제가 끝났는가? ($x_2$) ➡️ 보통 중요함. 중요도(가중치 $w_2 = 5$)
  3. 배가 고픈가? ($x_3$) ➡️ 별로 안 중요함. 중요도(가중치 $w_3 = 1$)

각 질문에 중요도를 곱해 점수를 매긴 뒤($w_1 x_1 + w_2 x_2 + w_3 x_3$), 나의 기본 귀차니즘(편향 $b$)을 넘어서면 "외출(1)", 못 넘으면 "집콕(0)"을 결정합니다. 이것이 퍼셉트론 1개의 수학적 원리입니다.

💡 XOR 문제와 다층 퍼셉트론(MLP)의 탄생
뇌세포 1개(단층 퍼셉트론)는 자로 선 하나를 긋는 것밖에 못 해서, 대각선으로 엇갈린 XOR(같으면 0, 다르면 1) 문제를 절대 풀 수 없었습니다.
학자들은 뇌세포를 여러 겹으로 쌓고(은닉층 추가), 직선이 아닌 곡선 형태의 활성화 함수(Activation Function)를 도입하여 이 문제를 완벽하게 해결했습니다.

2. 활성화 함수: 왜 시그모이드 대신 ReLU를 쓸까?

  • 시그모이드 (Sigmoid): 입력값을 0과 1 사이로 부드럽게 눌러줍니다. 하지만 층이 깊어지면 계산 도중 기울기(변화량)가 0으로 사라져버려 학습이 멈추는 기울기 소실(Vanishing Gradient) 문제가 발생합니다.
  • ReLU: 0보다 작으면 0으로 버리고, 0보다 크면 그대로 통과시킵니다. 계산이 매우 빠르고 깊은 층에서도 기울기가 사라지지 않아 현대 딥러닝의 표준으로 사용됩니다.

3. 오류 역전파 (Backpropagation) - 컴퓨터가 반성하며 배우는 법

컴퓨터가 사진을 보고 "강아지"라고 틀린 답을 냈을 때, "오차가 왜 생겼지?"를 출력층에서부터 거꾸로 맨 앞 입력층까지 전파하면서 오차에 원인을 제공한 뇌세포 연결선(가중치)을 조금씩 줄이거나 늘려주는 핵심 학습 원리입니다.

5단계. 실전 딥러닝과 시각 인공지능 (CNN)

1. 합성곱 신경망 (CNN)은 왜 사진을 잘 볼까?

💡 [비유] 작은 돋보기로 사진을 훑어보기
사진을 한 줄로 길게 펴서 컴퓨터에 넣으면, 눈 위에 눈썹이 있고 코 옆에 볼이 있다는 상하좌우 위치 관계(공간 정보)가 전부 파괴됩니다.
CNN은 작은 돋보기(필터/커널)를 들고 사진의 왼쪽 위부터 오른쪽 아래까지 쓱 훑으면서 "여기 모서리가 있네", "여기 동그라미가 있네" 하며 형태를 파악합니다.
레이어 수행하는 역할 시험 포인트
합성곱 (Conv2D) 필터를 이동시키며 사물의 모서리, 질감 등의 특징을 추출 가중치($w$)가 학습됨
풀링 (MaxPooling2D) 사소한 배경을 버리고 가장 뚜렷한 특징만 남겨 해상도를 절반으로 축소 가중치 학습 없음 (연산량 절감)
드롭아웃 (Dropout) 공부할 때 뉴런의 20%를 무작위로 끄고 공부하여 과적합 방지 시험/실전에서는 끄고 예측

6단계. 새로운 것을 만드는 AI와 시험 총정리

1. 오토인코더 vs GAN (생성 적대 신경망)

  • 오토인코더: 큰 사진을 핵심 요약본(잠재 공간)으로 작게 줄였다가 다시 원본으로 복원하는 기술. 사진의 잡음(노이즈)을 제거하거나 비정상 데이터(이상치)를 잡아낼 때 씁니다.
  • GAN: 위조지폐범(생성자)과 경찰(판별자)이 서로 경쟁하는 구조입니다. 생성자는 경찰을 속이려고 점점 더 정교한 가짜 사진을 그리고, 경찰은 가짜를 잡으려고 눈이 더 날카로워집니다. 둘이 끊임없이 싸우다 보면 결국 실물과 구별할 수 없는 초고화질 사진이 만들어집니다.
🎯 시험 전 반드시 머릿속에 넣어야 할 7대 정답 공식
1. XOR 문제 해결: 단층 퍼셉트론 불가 ➡️ 다층 퍼셉트론(MLP) + 비선형 활성화 함수.
2. 기울기 소실 극복: 시그모이드 ➡️ ReLU 활성화 함수 사용.
3. 가장 추천하는 옵티마이저: Adam (속도 관성 + 보폭 조절 결합).
4. CNN 풀링의 특징: 가중치 계산이 없으며, 크기만 줄여 연산량을 아낌.
5. 암 진단 모델 평가: 환자를 놓치면 생명이 위험하므로 재현율(Recall)이 핵심.
6. 스팸 메일 필터 평가: 정상 메일을 스팸으로 지우면 안 되므로 정밀도(Precision)가 핵심.
7. 이진 분류 vs 다중 분류 손실 함수: 이진은 binary_crossentropy, 다중은 sparse_categorical_crossentropy.
