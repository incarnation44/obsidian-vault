## 🧭 [1. 인공지능이란 무엇인가? (01-01 ~ 01-03)]
* **기존 프로그램 vs 인공지능:**
  * 기존 프로그램: 사람이 정해준 If-Else 규칙대로만 기계적으로 동작.
  * 인공지능: 데이터(수많은 예시)를 보고 컴퓨터가 스스로 규칙과 가중치를 학습.
* **튜링 테스트(Turing Test):** 컴퓨터와 대화했을 때 사람인지 기계인지 구별하지 못하면 지능이 있다고 판정.
* **약인공지능(Narrow AI) vs 강인공지능(AGI):**
  * 약인공지능: 특정 도메인(바둑, 번역, 얼굴 인식)만 해결하는 AI (현재의 모든 AI).
  * 강인공지능: 인간처럼 스스로 의식과 범용적 사고 능력을 갖춘 만능 지능.
* **🚨 시험 핵심:** 1956년 다트머스 회의에서 '인공지능' 용어 공식 제정. 인간에게 쉬운 시각은 AI에게 어렵고, 수학 계산은 쉬운 현상을 **모라벡의 역설**이라 함.

## 🧭 [2. 파이썬 환경과 셈 지능 (02-01 ~ 02-04)]
* **Colab vs Anaconda:**
  * Colab: 브라우저 기반, 무료 GPU 제공.
  * Anaconda: 로컬 환경, conda 가상환경 관리자로 라이브러리 충돌 방지.
* **NumPy 수치 연산:**
  * 파이썬의 `for` 루프보다 C 언어 기반 연속 메모리와 SIMD를 사용하는 **벡터화 연산**이 수십 배 빠름.
  * `A * B`: 같은 위치끼리 곱하는 요소별 곱(Element-wise).
  * `A @ B` 또는 `np.dot(A, B)`: 가로줄과 세로줄을 곱해 더하는 행렬 곱 (시험 단골 구분!).

## 🧭 [3. 기계학습 기초 및 성능 평가 지표 (03-01 ~ 03-05)]
* **학습 유형:**
  * 지도학습 (회귀: 연속 숫자 예측 / 분류: 범주 판별)
  * 비지도학습 (군집화 K-Means, 차원 축소 PCA)
  * 강화학습 (보상을 극대화하는 행동 정책 학습)
* **과적합(Overfitting):** 훈련 데이터에 너무 지나치게 맞춰져 새로운 시험 문제(테스트 데이터)에서 오차가 급증하는 현상.
* **🚨 4대 평가 지표 시험 수식:**
  * **정확도(Accuracy):** $\frac{TP + TN}{TP + TN + FP + FN}$ (클래스 비율 균형 시)
  * **정밀도(Precision):** $\frac{TP}{TP + FP}$ (스팸 메일 필터링 등 정상 메일을 스팸으로 지우면 안 될 때)
  * **재현율(Recall):** $\frac{TP}{TP + FN}$ (암 진단 모델 등 실제 암 환자를 놓치면 안 될 때)
  * **F1-Score:** 정밀도와 재현율의 조화평균 (데이터 불균형 시 필수).

## 🧭 [4. 신경망과 퍼셉트론, 오류 역전파 (04-01 ~ 04-05)]
* **단층 퍼셉트론과 XOR 문제:**
  * 단층 퍼셉트론은 선형 분리 가능한 문제(AND, OR)만 해결 가능.
  * 대각선으로 엇갈린 XOR 문제는 풀 수 없어 1차 AI 겨울 초래.
  * **해결책:** 은닉층을 추가한 다층 퍼셉트론(MLP)과 비선형 활성화 함수로 해결!
* **활성화 함수:**
  * `Sigmoid`: 층이 깊어지면 미분값이 0에 수렴하는 **기울기 소실(Vanishing Gradient)** 발생.
  * `ReLU`: 0 이하는 0, 0 초과는 그대로 통과시켜 기울기 소실을 극복한 현대 딥러닝 표준.
  * `Softmax`: 다중 분류 출력층에서 모든 클래스 확률의 합을 1.0으로 만듦.
* **오류 역전파(Backpropagation):** 출력층의 오차에서 출발하여 연쇄 법칙(Chain Rule)을 적용해 각 층의 가중치를 역방향으로 전파하며 갱신.

## 🧭 [5. 딥러닝 실전과 TensorFlow (05-01 ~ 05-05)]
* **손실 함수(Loss):**
  * 회귀: `mean_squared_error` (MSE)
  * 이진 분류: `binary_crossentropy`
  * 다중 분류: `sparse_categorical_crossentropy` (정수 라벨)
* **옵티마이저(Optimizer):**
  * `SGD` ➡️ `Momentum` ➡️ `RMSprop` ➡️ `Adam` (모멘텀의 관성 + RMSprop의 적응형 보폭 결합, 기본 추천).
* **과적합 방지 4대 전략:** 드롭아웃(Dropout), 데이터 증강(Augmentation), 가중치 규제(L1/L2), 조기 종료(Early Stopping).

## 🧭 [6. 이미지 인식과 합성곱 신경망 (CNN) (06-01 ~ 06-04)]
* **CNN을 쓰는 이유:** 이미지를 1차원으로 펼치면 픽셀의 상하좌우 공간 정보가 파괴되므로, 작은 필터(커널)를 슬라이딩하여 공간 특징을 유지.
* **CNN 레이어 비교:**
  * `Conv2D`: 필터를 이동하며 특징 맵(Feature Map) 생성 (가중치 학습 있음).
  * `MaxPooling2D`: 가장 큰 값만 골라 해상도 축소 및 이동 불변성 획득 (**가중치 학습 없음**).
* **출력 크기 공식:** $O = \frac{W - F + 2P}{S} + 1$ (W:입력, F:필터, P:패딩, S:스트라이드).
* **전이 학습(Transfer Learning):** ImageNet으로 사전학습된 모델(VGG, ResNet)의 가중치를 가져와 출력층만 미세 조정(Fine-Tuning).

## 🧭 [7. 생성 모델 (오토인코더, GAN) & 시험 7계명 (07-01 ~ 08-01)]
* **오토인코더:** 인코더(압축) ➡️ 잠재 공간(Latent Space) ➡️ 디코더(복원). 노이즈 제거와 이상치 탐지에 활용.
* **GAN (생성 적대 신경망):** 생성자(가짜 생성)와 판별자(진짜/가짜 판별)가 서로 경쟁하는 Minimax 게임을 통해 초고화질 이미지 생성.
* **🎯 시험 7대 족보:**
  1. XOR 문제 ➡️ 다층 퍼셉트론(MLP)으로 해결.
  2. 기울기 소실 ➡️ ReLU 활성화 함수로 해결.
  3. 기본 옵티마이저 ➡️ Adam.
  4. CNN 풀링 레이어 ➡️ 가중치 학습 없이 크기만 축소.
  5. 암 환자 진단 ➡️ 재현율(Recall)이 가장 중요.
  6. 스팸 메일 필터 ➡️ 정밀도(Precision)가 가장 중요.
  7. 정규화 공식 ➡️ $X_{\text{norm}} = \frac{X - X_{\min}}{X_{\max} - X_{\min}}$.
