# 🏛️ AI Investment & Business Idea Debate Engine

This skill pits Warren Buffett, Michael Burry, and Peter Lynch against each other to ruthlessly stress-test any stock or business idea.

## 🛠️ Execution Command

실존 경로:

```powershell
python "C:\Users\ildoc\.gemini\antigravity\scratch\my_ai_workspace\core\investor_debate.py" "<종목명 또는 비즈니스 아이디어>"
```

## 📋 4대 검증 축
1. **🏛️ 워렌 버핏**: 경제적 해자(Moat), 10년 지속가능성, 현금흐름 창출력
2. **🩸 마이클 버리**: 숨겨진 뇌관, 규제/플랫폼 리스크, 최악의 시나리오
3. **🛒 피터 린치**: 일상 직관적 수요, 바이럴 확장성, 텐배거 잠재력
4. **⚖️ 의장 판정**: 최종 추진 등급 + 핵심 기회 3 + 치명적 리스크 3 + 3단계 즉시 실행 계획
