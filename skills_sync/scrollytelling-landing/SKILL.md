# 🚀 10K Cinematic Interactive Scrollytelling Builder

This skill builds award-winning, luxury interactive landing pages with scroll-driven storytelling in minutes.

## 🌟 4 Core Principles

1. **Scrollytelling (시네마틱 스크롤 애니메이션)**:
   - 마우스 휠을 내릴 때마다 상품의 핵심 부품이 조립되거나 시각적 3D 효과가 연출되는 CSS/JS 스크롤 애니메이션 적용.
2. **Zero Cliché, 100% Tactile Luxury**:
   - 싸구려 AI 템플릿(보라색 그라디언트, 네온 테두리) 배제.
   - Pretendard 타이포그래피, 완벽한 반응형 모바일 뷰, 초고속 0.1초 로딩 속도 유지.
3. **High-Converting Lead Funnel (고전환 리드 수집 파이프라인)**:
   - 페인포인트 ➔ 해결책 ➔ 사회적 증거(영상/텍스트 후기) ➔ 즉시 신청/상담 폼(Tally 연동) 구성.
4. **1-Click Export / Deployment**:
   - 단일 HTML/CSS/JS 또는 Next.js 번들로 즉시 다운로드 및 Vercel/Cloudflare 배포 가능.
