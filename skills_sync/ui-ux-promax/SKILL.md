## 📑 2. 프로페셔널 PDF 교재 & 문서 디자인 원칙 (Anti-AI Report)

PDF 교재나 요약 문서를 만들 때 "AI가 자동 생성한 조잡한 마크다운 출력물" 느낌을 완벽하게 제거하는 원칙:

1. **상단 히어로 배너 & 헤더**: 단순 검정 글씨 대신 브랜드 컬러 악센트 바, 깔끔한 날짜/출처 메타데이터 배지 적용.
2. **2단/3단 모듈형 정보 카드**: 텍스트를 줄줄이 나열하지 않고 `요약 ➔ 핵심 원리 ➔ 실전 족보`를 명확한 카드 블록으로 구분.
3. **표(Table) 스타일링**: 밋밋한 흑백 선 대신 부드러운 헤더 배경(`hsl(210, 30%, 96%)`), 지브라 스트라이프, 넉넉한 셀 패딩(8~12px).
4. **시각적 비유 콜아웃 박스**: 일상 비유와 시험 팁을 부드러운 라운딩 처리된 강조 박스(`> [!TIP]`, `> [!NOTE]`)로 시각화.

## 🎯 3. 고품질 카피라이팅 (Human Copywriting)

* ❌ "최첨단 의료 기술을 만나보세요"
* ⭕ "대표원장이 처음부터 끝까지 1:1로 직접 진료합니다" (신뢰와 감성 직결)
