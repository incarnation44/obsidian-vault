성장 과정

서울에서 태어나 네 살 때부터 스무 살까지 태국에서 자랐습니다. 처음에는 아버지의 사업을 따라간 이주였지만, 결과적으로 그 시간이 제 가장 큰 자산이 되었습니다. 태국 유치원부터 시작해 고등학교까지 국제학교를 다니면서 영어와 태국어를 일상어로 쓰고, 십여 개 국적의 친구들과 공부했습니다. 다른 사람이 당연하게 여기는 것들을 낯설게 보고 질문하는 습관이 그때 생겼습니다.

한국에 돌아와 건국대학교 경영학과에 재외국민 특례로 입학했지만, 상황이 여의치 않았습니다. 가정 형편이 어려워지면서 학비와 생활비는 전부 제 몫이었습니다. 통역, 과외, 서빙, PC방 아르바이트 등 안 가리고 했고, 그 과정에서 일을 대하는 태도가 자연스럽게 단단해졌습니다. 군 복무를 마치고 복학을 준비하던 중, 서빙으로 시작한 일이 홀 매니저 자리까지 이어졌습니다. 그게 창업의 시작이었습니다.

이후 20대 후반부터 30대 후반까지 10년 넘게 고깃집을 직접 운영했습니다. 하루 15시간, 쉬는 날 없이. 잘 될 때도 있었고 힘들 때도 있었습니다. 코로나 이후 매출이 무너지면서 진지하게 생각했습니다. 가족까지 힘들어지는 상황을 반복하고 싶지 않았고, 어디서든 써먹을 수 있는 기술을 갖고 싶었습니다. 그게 IT로 방향을 튼 이유입니다.

지원 동기

장사를 10년 넘게 하면서 IT와의 접점이 점점 많아졌습니다. 배달앱, POS 시스템, 재고 관리 프로그램, SNS 마케팅. 사용하는 입장에서 "이게 어떻게 돌아가는 걸까"라는 궁금증이 쌓였고, 불편한 기능을 발견할 때마다 "내가 만들 수 있다면 이렇게 바꿀 텐데"라는 생각을 자주 했습니다.

KH정보교육원에서 공부를 시작하면서 그 궁금증이 실체가 됐습니다. 처음 자바 코드가 컴파일되고, 스프링으로 만든 API가 실제로 응답을 돌려줄 때의 느낌은 꽤 강렬했습니다. 어떤 일을 할 때 "더 알고 싶다"는 감각이 오랜만에 돌아왔습니다.

나이가 적지 않다는 건 압니다. 하지만 이미 한 번 완전히 새로운 분야에서 처음부터 시작해 10년을 버텨본 경험이 있습니다. 그리고 이번엔 기술로 승부하고 싶습니다. 국내를 넘어 영어권 어디서든 일할 수 있는 개발자가 되는 것이 지금의 목표입니다.

성격의 장단점

가장 큰 강점은 버티는 힘입니다. 가게가 안 풀리는 시즌에도, 공부하다 막히는 날에도, 그냥 계속하는 게 체질이 되어 있습니다. 개발을 공부하면서도 이해가 되지 않는 부분이 생기면 넘기지 못하는 편입니다. 비효율적으로 보일 수 있지만, 그 부분을 짚고 넘어가지 않으면 나중에 더 큰 문제가 된다는 걸 경험으로 알고 있습니다.

또 하나는 사람을 읽는 감각입니다. 10년 동안 직원을 뽑고 관리하고, 손님 수백 명을 매일 상대하면서 얻은 것입니다. 팀 프로젝트에서도 누가 막혀 있는지, 어디서 소통이 어긋나는지 빠르게 파악하는 편이었습니다.

단점은 준비가 충분하지 않으면 시작을 늦추는 경향입니다. 장사할 때도 완전히 준비된 상태에서 시작하려다 오히려 타이밍을 놓친 경험이 있습니다. 지금은 일단 동작하는 것부터 만들고 개선해 나가는 방식에 익숙해지고 있습니다.

기술 및 학습 경험

KH정보교육원에서 약 6개월간 자바 기반 풀스택 개발 과정을 수료했습니다(2025.10 ~ 2026.04). 자바 기본 문법과 객체지향 프로그래밍을 시작으로, 스프링 부트, JPA, MyBatis, MySQL을 활용한 백엔드 개발을 배웠고, 프론트엔드는 HTML/CSS/JavaScript와 리액트를 함께 공부했습니다.

  • Java · 객체지향 설계 · 컬렉션 프레임워크 · 예외 처리
  • Spring Boot · Spring MVC · REST API 설계
  • JPA / MyBatis · MySQL 데이터베이스 설계
  • React · HTML/CSS · JavaScript (ES6+)
  • Git · GitHub 버전 관리 · Postman API 테스트

강의를 수동적으로 따라가기보다 직접 기능을 만들고 오류를 해결하는 방식으로 학습했습니다. 회원 관리, 게시판, 로그인, REST API 등 기본적인 기능을 반복해서 구현하며 백엔드 전체 흐름을 익혔습니다.

프로젝트 및 협업 경험

수료 전 팀 프로젝트에서는 백엔드 API 설계와 데이터베이스 연동을 주로 담당했습니다. 처음에는 기능 완성에 집중하다가 예외 처리와 유효성 검사를 나중에 고치는 패턴을 반복했고, 이후에는 처음부터 예외 상황을 고려하는 습관을 들였습니다.

팀 프로젝트에서 Git 브랜치 전략을 사용하면서 충돌이 발생했을 때 감으로 덮어쓰지 않고 변경 내역을 확인하고 팀원과 소통하며 정리하는 방식을 배웠습니다. 10년간 직원들과 일하면서 얻은 소통 감각이 팀 프로젝트에서도 도움이 됐습니다.

개발에서 가장 크게 느낀 점은 구조 설계가 이후 작업 속도를 결정한다는 것이었습니다. 컨트롤러, 서비스, 리포지토리 역할을 분리해 개발해보니 기능 추가나 수정이 훨씬 수월했고, 그 경험이 계층형 구조의 필요성을 몸으로 이해하게 해줬습니다.

입사 후 포부

처음에는 배우는 사람으로 들어갈 것입니다. 그 자세를 잃지 않겠습니다. 모르는 부분은 먼저 스스로 파고들고, 일정 시간 이상 해결되지 않으면 현재까지 확인한 내용을 정리해서 물어보는 방식으로 팀에 부담을 최소화하겠습니다.

중기적으로는 자바 스프링 기반의 백엔드 역량을 깊이 쌓아 혼자 구조를 설계하고 문제를 해결할 수 있는 개발자가 되고 싶습니다. 장기적으로는 영어 실력을 살려 글로벌 환경에서도 기여할 수 있는 개발자가 목표입니다. 해외 팀과의 협업이나 해외 근무도 부담 없이 소화할 수 있습니다.

지금 가장 절실한 사람이 저라는 건 압니다. 그 절실함을 코드로 증명하겠습니다.
