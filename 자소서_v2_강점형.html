01
지원 동기

10년 넘게 장사를 하면서 늘 가장 신경 쓴 것은 하나였습니다. 손님이 불편하지 않게, 직원이 실수하지 않게, 재고가 어긋나지 않게. 결국 장사도 시스템이 잘 돌아가느냐의 문제였습니다. 배달앱이 뜨면서 직접 써보고, POS 시스템이 바뀔 때마다 익히면서 어느 순간부터 "이걸 만드는 쪽이 되고 싶다"는 생각이 구체화됐습니다.

코로나로 가게 사정이 어려워지면서 방향을 새로 잡았습니다. 판단 기준은 단순했습니다. 내 기술 하나로 한국이 아닌 어디서도 먹고살 수 있는가. IT 개발이 그 답이었습니다. 영어는 이미 국제학교를 졸업하며 실전으로 익혔고, 기술만 갖추면 무대를 선택할 수 있다고 생각했습니다.

"전직도 많고 나이도 많다는 걸 압니다. 그래서 더 절실합니다. 이미 한 분야에서 처음부터 시작해 10년을 버텨봤습니다. 이번엔 기술로 해보겠습니다."
02
강점 — 10년 창업 경험이 개발자에게 주는 것

신입 개발자 대부분이 가지지 못한 경험이 있습니다. 실제 서비스가 망하는 걸 직접 경험해본 것입니다. 장사가 안 풀릴 때, 직원이 갑자기 그만둘 때, 식재료 가격이 올라 마진이 사라질 때. 그 상황들을 하나하나 헤쳐나오면서 "지금 당장 해결할 수 있는 것부터 찾는" 습관이 생겼습니다.

위기 대처 능력
예상치 못한 상황에서 패닉하지 않고 원인을 분리해 우선순위를 정하는 습관. 개발 오류 디버깅에 그대로 적용됩니다.
사람 관리 경험
수년간 직원을 채용하고 관리하며 소통. 팀 프로젝트에서 서로 막히는 지점을 먼저 파악하고 조율합니다.
버티는 체력과 정신력
하루 15시간, 쉬는 날 없이 10년. 야근, 빡빡한 마감, 연속된 오류 앞에서 무너지지 않습니다.
사용자 관점
수만 명의 고객을 직접 상대한 경험. 기능이 아니라 사람이 실제로 쓸 때 어디서 불편한지 감각적으로 이해합니다.
03
성장 과정

서울 출생, 태국 거주 16년. 아버지 사업을 따라 네 살에 태국으로 건너가 국제학교를 졸업했습니다. 영어와 태국어를 일상어로 쓰며 자랐고, 다양한 국적과 문화권의 사람들과 섞이는 것을 자연스럽게 받아들이는 감각이 이때 생겼습니다.

건국대 경영학과 재외국민 특례 입학 후, 가정 형편이 어려워지면서 통역·과외·서빙·PC방 등 아르바이트를 병행하며 학비와 생활비를 스스로 해결했습니다. 군 복무 후 복학 대신 홀 매니저로 일하다가 창업으로 이어졌고, 이후 10년 이상 요식업을 운영했습니다.

코로나를 기점으로 진로를 IT로 전환, KH정보교육원 자바 개발자 과정을 2025년 10월부터 2026년 4월까지 수료했습니다.

04
기술 역량

자바 기본 문법과 객체지향 설계를 기반으로, 스프링 부트와 JPA를 활용한 백엔드 API 설계·구현 능력을 갖추고 있습니다. 프론트엔드는 React와 JavaScript로 기본적인 SPA 구현이 가능하며, Git을 이용한 브랜치 관리와 협업 개발 경험이 있습니다.

Java Spring Boot Spring MVC JPA MyBatis MySQL React JavaScript HTML / CSS Git / GitHub REST API Postman
05
프로젝트 및 문제 해결 경험

팀 프로젝트에서 백엔드 API 설계와 DB 연동을 담당하며 회원가입, 로그인, 게시판, 데이터 조회 기능을 구현했습니다. 처음에 기능 구현에 집중하다 예외 처리를 나중에 보완하는 패턴을 반복했고, 이후에는 요청 입력값 검증과 예외 처리를 처음 설계 단계에서 고려하는 습관으로 바꿨습니다.

데이터가 정상적으로 저장되지 않는 문제가 생겼을 때는 로그를 확인하고 요청 흐름을 단계별로 추적했습니다. 장사할 때 "어디서 돈이 새는지 먼저 찾고 막는다"는 방식이 디버깅에서도 그대로 통했습니다. 증거 없이 감으로 수정하지 않는 것이 제 원칙입니다.

06
입사 후 포부

입사 초반에는 조직의 코드와 업무 흐름을 빠르게 파악하는 데 집중하겠습니다. 모르는 것은 숨기지 않고, 스스로 정리해서 질문하겠습니다. 이미 완전히 새로운 분야에서 처음부터 배워 본 경험이 있기 때문에, 낯선 환경에서 적응하는 속도는 자신 있습니다.

중기적으로는 자바 스프링 백엔드 역량을 쌓아 구조를 직접 설계하고 성능 문제까지 판단할 수 있는 개발자가 되겠습니다. 장기적으로는 영어 역량을 살려 글로벌 팀 협업이나 해외 근무에도 기여할 수 있는 개발자가 되는 것이 목표입니다.

10년 장사해서 쌓은 것은 기술이 아닌 태도입니다. 그 태도를 코드로 옮기는 중입니다.
